Guoliang Li (VLDB 2017)

1. Hybrid Intelligence

When Algorithms Stumble: Intelligent Crowdsourcing for Data Integration

Pure machine learning can quickly resolve 95% of obvious data integration matches: "iPad 64GB" == "Apple iPad 64GB". But the remaining 5% are subtle edge cases where machines make catastrophic errors.

👥 The Dilemma: • Pure AI: Fast and free, but error-prone on hard ambiguities.
• Pure Human Crowdsourcing: 100% accurate, but wildly expensive and impossible for 10 million record pairs!

Guoliang Li (VLDB 2017) at Tsinghua University formalized Human-in-the-Loop (HIL) Data Integration, solving how to optimize budget, worker noise, and active learning uncertainty routing.
2. Mathematical Formalism

Active Learning Uncertainty Routing & The Dawid-Skene Worker Model

HIL routes records across three distinct tiers based on machine prediction confidence $P(\t\text{Match})$:

Three-Tier Confidence Routing:
1. Auto-Accept: If P(Match) ≥ τ_high (e.g. 0.95) ➔ Machine marks MATCH (Cost: $0).
2. Auto-Reject: If P(Match) ≤ τ_low (e.g. 0.05) ➔ Machine marks NON-MATCH (Cost: $0).
3. Human Review: If τ_low < P(Match) < τ_high ➔ Route to Crowd Worker!

Worker Quality Modeling (Dawid-Skene):
Human workers are imperfect (error rate e_w). By assigning K workers to a hard task and running Expectation-Maximization (EM), the system jointly estimates true match probability and worker reliability.

Test Your Understanding

Explanation: Correct! HIL combines machine scalability with human semantic reasoning at minimal monetary cost.

2. In active learning uncertainty sampling, which records are sent for human annotation?

Explanation: Correct! High-uncertainty pairs provide the maximum informational gain per dollar spent.

3. How does the Dawid-Skene model handle noisy crowd workers?

Explanation: Correct! The EM algorithm separates reliable workers from noisy or spammy workers mathematically.

4. What happens if the human review band is set too wide (e.g., [0.05 - 0.95])?

Explanation: Correct! A wider band routes too many pairs to humans, wasting budget on obvious matches.

Explanation: Correct! Active learning continuously re-fits the model with every batch of human-verified answers.
