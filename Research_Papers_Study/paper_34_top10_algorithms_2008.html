2. Comparative Algorithmic Taxonomy

Categorization by Machine Learning Paradigm

Algorithm Learning Paradigm Core Mathematical Principle
1. C4.5 / CART Supervised Classification Greedy recursive splitting via Information Gain Ratio / Gini Impurity.
2. k-Means Unsupervised Clustering Minimizing within-cluster sum-of-squares (WCSS) via iterative centroid updates.
3. SVM Supervised Classification Maximum-margin hyperplane separation with kernel trick for non-linearity.
4. Apriori Unsupervised Association Anti-monotone support pruning over lattice powersets.
5. EM (Expectation-Maximization) Unsupervised / Density Maximum likelihood estimation in the presence of latent unobserved variables.
6. PageRank Graph / Link Analysis Random walk stationary distribution via dominant eigenvector power iteration.
7. AdaBoost Supervised Ensemble Sequential error-reweighting of weak learners into a high-margin classifier.
8. k-NN Instance-Based Lazy Non-parametric local metric voting; zero explicit training phase.
9. Naive Bayes Supervised Probabilistic Bayes' Theorem with conditional feature independence assumption.

4. Active Retention Quiz

Test Your Understanding

1. Which algorithm among the Top 10 has NO explicit training phase and stores all raw training records in memory?

Explanation: Correct! k-NN simply memorizes the training data and postpones all computation until inference.

2. What enables Support Vector Machines (SVMs) to construct non-linear decision boundaries efficiently?

Explanation: Correct! Mercer kernels allow linear hyperplanes to solve complex non-linear classification problems.

3. How does AdaBoost turn weak classifiers (e.g. decision stumps) into a strong ensemble?

Explanation: Correct! AdaBoost trains sequentially, adapting instance distribution weights at every step.

4. What is the fundamental convergence limitation of standard k-Means clustering?

Explanation: Correct! k-Means can become trapped in poor local optima, which motivated k-Means++ initialization.

5. What makes Naive Bayes surprisingly resilient even when feature independence is violated?

Explanation: Correct! The rank order of class scores is often preserved even when independence assumptions fail.
