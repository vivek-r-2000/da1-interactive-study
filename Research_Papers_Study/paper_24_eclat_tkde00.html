1. Vertical Data Revolution

Mining Without Database Scans: The Power of TID-Lists

Apriori scans the horizontal database on every single pass $k$. In 2000, Mohammed J. Zaki revolutionized pattern mining by introducing ECLAT (Equivalence Class Clustering and Tree Growth) using the Vertical Data Format.

⚡ The Core Concept: Instead of TID ➔ {Item1, Item2, ...}, store:
Item ➔ {TID_1, TID_4, TID_7, ...} (The TID-List).

To compute the support of itemset $\{A, B\}$, you do ZERO database scans! You simply compute the intersection of two sorted integer lists:
$$\t\text{TID}(AB) = \t\text{TID}(A) \cap \t\text{TID}(B)$$ $$\t\text{Support}(AB) = |\t\text{TID}(AB)|$$
2. The Memory Bottleneck & Diffset Solution

Diffsets: Shrinking TID-Lists by 95%

In dense datasets (e.g. telecommunications or census), frequent items appear in almost every transaction. If a database has 10 million rows, $\t\text{TID}(A)$ has 8 million integers, and $\t\text{TID}(B)$ has 8 million integers. Intersecting and storing these lists exhausts gigabytes of RAM.

The Diffset Equation (dEclat):
Instead of storing which transactions CONTAIN the itemset, store which transactions in parent TID(A) DO NOT contain item B!

Diffset(AB) = TID(A) \setminus TID(B)

Recursive Diffset Computation:
Diffset(ABC) = Diffset(AC) \setminus Diffset(AB)

Support Calculation from Diffsets:
Support(AB) = Support(A) - |Diffset(AB)|
💡 Why This Is A Superpower: If $TID(A)$ has 1,000,000 IDs and $TID(AB)$ has 999,000 IDs:
• Full TID-list storage: 999,000 integers (~4 Megabytes).
• Diffset storage: Exactly 1,000 integers (~4 Kilobytes)!
A 99.9% memory reduction! As patterns grow longer, diffsets get smaller and smaller, whereas standard TID-lists remain huge.

4. Active Retention Quiz

Test Your Understanding

1. How does ECLAT compute the support of an itemset {X, Y}?

Explanation: Correct! The vertical TID-list intersection gives exactly the transactions containing both items.

2. If TID(A) = {1, 2, 3, 4, 5} and TID(B) = {2, 3, 5}, what is Diffset(AB)?

Explanation: Correct! Diffset(AB) consists of the transaction IDs that are in A but missing from B: {1, 2, 3, 4, 5} \ {2, 3, 5} = {1, 4}.

3. How is the support of AB recovered from Diffset(AB)?

Explanation: Correct! Because Diffset contains the missing transactions, subtracting its size from the parent support gives the exact count.

4. What lattice search strategy does ECLAT use?

Explanation: Correct! DFS explores branches deeply, allowing intermediate TID lists to be released from memory immediately after exploring that branch.

5. In what kind of database do Diffsets provide the greatest memory savings?

Explanation: Correct! When support is high, the difference set contains very few elements, saving up to 99% of memory.
