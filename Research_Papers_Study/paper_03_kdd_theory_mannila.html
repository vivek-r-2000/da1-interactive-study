Theoretical Frameworks for Data Mining

Heikki Mannila (PKDD 2000)

⏱️ Focus: 15:00
1. Mathematical Grounding

What is the Formal Logic Behind Data Mining?

Relational databases have Edgar Codd's Relational Algebra. But what is the mathematical foundation of Data Mining? In 2000, Heikki Mannila provided the unifying logic foundation: Inductive Databases.

📜 Mannila's Master Definition: Let $D$ be a database. Let $\mathcal{L}$ be a formal pattern language. Let $q(\phi, D)$ be a selection predicate.

Data mining is simply computing the Theory of the Database: $$\mathcal{T}\text{h}(\mathcal{L}, D, q) = \{ \phi \in \mathcal{L} \mid q(\phi, D) \text{ is True} \}$$ Data mining is nothing more than declarative query optimization over pattern spaces!
2. Mathematical Formalism

Condensed Representations & Version Spaces

Condensed Representations:
If Th(L, D, q) contains 1,000,000 patterns, can we represent it losslessly using only 1,000 patterns?

• Frequent Closed Itemsets: Represent all itemset supports without loss of information.
• Maximal Frequent Itemsets: Define the positive border of the version space.
• Condensed Border: The boundary dividing True sentences in L from False sentences.
