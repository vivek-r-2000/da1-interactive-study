⚡ Key Formulas at a Glance

The most-tested formulas from the entire course — bookmark this page and revisit before exams.

📦 Support
support(A→B) = P(A∪B)
Fraction of all transactions that contain both A and B. Measures how often the rule appears.
🎯 Confidence
conf(A→B) = P(B|A) = sup(A∪B)/sup(A)
Given A was bought, how likely is B also bought? Measures reliability of the rule.
🌿 Gini Index
Gini = 1 − Σ pᵢ²
Measures impurity in a node. 0 = perfectly pure node. Used in decision tree splits.
📐 Entropy
H = − Σ pᵢ · log₂(pᵢ)
Measures disorder/surprise in a dataset. 0 = all same class. Max when classes are equally likely.
📏 Euclidean Distance
d(p,q) = √( Σ (pᵢ − qᵢ)² )
Straight-line distance between two points in n-dimensional space. Used in k-NN & clustering.
📈 Lift
lift(A→B) = conf(A→B) / sup(B)
lift > 1 → A and B are positively correlated. lift = 1 → independent. lift < 1 → negatively correlated.
🍅 How to Use This Course
🍅 The Pomodoro Technique
Each module has a built-in 15-minute Pomodoro timer. When it rings, take a genuine 5-minute break — stand up, stretch, drink water. Your brain consolidates memory during breaks, not during studying.
🃏 One Card at a Time
Every module is broken into small "cards" of max ~200 words each. Don't skip ahead. The flip-cards (active recall) are more valuable than re-reading — always try to answer before flipping.
🎮 Interact with Visualizations
Each module has at least 2 interactive visualizations. Click, drag, and play with them — the goal is intuition, not memorization. If you understand why a concept works, you can reconstruct any formula.
📝 End-of-Module Quiz
Each module ends with a 5-question quiz. Score < 3/5 → revisit the weak section. Score 5/5 → you're ready to move on. No cheating — it only hurts you in the exam!
📅 Suggested Study Order
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08. Each module builds on the previous. Module 08 (Classification) is the longest — schedule it when you have 90 uninterrupted minutes.
