Garbage In, Garbage Out
The #1 rule of data quality
🍳 Imagine feeding a recipe to a robot chef — but the recipe has missing steps, wrong measurements, and some pages are duplicated. The robot will produce garbage food. Same with data — garbage in, garbage out. Preprocessing fixes the recipe.

Real-world data is messy. It comes from many sources, collected by different people, at different times, with different tools.

Before we can mine patterns or build models, we must clean and prepare the data. This is called data preprocessing and takes up ~80% of a data scientist's time.

💡 Why This Matters Even the best machine learning algorithm will fail if fed dirty data. Preprocessing is the single most impactful step in any data project.

Measuring Difference
Why do we need distance measures?
🎬 How different are two movies? 🗺️ How far apart are two cities? In data mining, we need to mathematically measure how similar or different two data points are. This is called a dissimilarity measure (or distance).

Algorithms like k-NN, k-Means clustering, and recommendation systems all rely on computing similarity between data points.

The key insight: similar things should have low distance; different things should have high distance.

📐
Distance
0 = identical, bigger = more different
🤝
Similarity
1 = identical, 0 = completely different

Cosine Similarity
Angle between vectors, not length
🧭 Two arrows pointing northeast are similar, even if one is twice as long. Cosine similarity measures the angle between them, not their length. Used heavily in text analysis.
cos(θ) = (A · B) / (|A| × |B|)

A · B is the dot product. |A| and |B| are the magnitudes (lengths).

Range: [-1, 1]. For text documents (non-negative counts), range is [0, 1].

🛒
Jaccard Similarity
For comparing sets
🛒 Two shopping baskets: what fraction of all items do they share? That's Jaccard similarity — shared items divided by all distinct items combined.
J(A,B) = |A ∩ B| / |A ∪ B|
Example:
Basket A: {milk, bread, eggs}
Basket B: {milk, bread, butter}
Shared (A∩B): {milk, bread} → |A∩B| = 2
Combined (A∪B): {milk, bread, eggs, butter} → |A∪B| = 4
J(A,B) = 2/4 = 0.5 (50% similar)

Nominal Attributes
Categories without order
🎨 Color categories: red, blue, green. There's no "more" or "less" — they're just different. Nominal attributes are names/labels with no inherent ordering.

For nominal attributes, dissimilarity is binary:

d(A,B) = 0 if same value
d(A,B) = 1 if different value
PersonHair ColorEye Color
AliceBrownBlue
BobBlackBlue
d(Hair) = 1 (different)  |  d(Eye) = 0 (same)

Overall dissimilarity = (# mismatches) / (total attributes) = 1/2 = 0.5

📊 SIMILARITY & DISTANCE • Card 13 of 30 CONCEPT
📊
Ordinal Attributes
Categories WITH order
🏅 Gold, Silver, Bronze — these have an order! "Gold" is better than "Silver." Ordinal attributes have a meaningful sequence.

Examples: Small/Medium/Large, Poor/Fair/Good/Excellent, Freshman/Sophomore/Junior/Senior

Method: Map ranks to [0,1] scale, then use numeric distance.

rᵢ = (rank − 1) / (M − 1)

where M = number of possible values

Example: Size {Small=1, Medium=2, Large=3}, M=3
Small → (1−1)/(3−1) = 0.0
Medium → (2−1)/(3−1) = 0.5
Large → (3−1)/(3−1) = 1.0
d(Small, Large) = |0.0 − 1.0| = 1.0 (maximum)

❓ DATA CLEANING • Card 16 of 30 CONCEPT
❓
Handling Missing Values
6 strategies, from simple to smart
1. Ignore the row — skip records with missing values. Risky if many rows are missing.
2. Fill manually — look up the value. Accurate but slow and impossible at scale.
3. Global mean/median/mode — fill all blanks with the column average. Fast but ignores context.
4. Use a constant — fill with "Unknown" or 0. Simple but creates a new artificial category.
5. Class-specific mean — use the mean for that class only. E.g., average age for "students" vs "professors."
6. Predict with a model — use regression or k-NN to predict the missing value. Most accurate!
💡 Rule of Thumb Methods 3, 5, and 6 are most common in practice. Method 6 is best but requires existing data to train on.

Handling Noisy Data — Binning
Smoothing by grouping similar values
🛣️ Imagine a bumpy road. Instead of fixing every bump individually, you average out the bumps in each section to get a smooth road. That's binning — smooth local variations.

Binning: Divide sorted data into "bins" (buckets), then replace each value with a smoothed version.

Original sorted prices: [4, 8, 9, 15, 21, 21, 24, 25, 26, 28, 29, 34]
Bin 1: [4, 8, 9, 15] → Mean = 9 → Smoothed: [9, 9, 9, 9]
Bin 2: [21, 21, 24, 25] → Mean = 22.75 → Smoothed: [23, 23, 23, 23]
Bin 3: [26, 28, 29, 34] → Mean = 29.25 → Smoothed: [29, 29, 29, 29]

You can smooth by: bin mean, bin median, or bin boundaries (snap to nearest edge).

Equal-Width vs Equal-Depth Binning
Two different ways to create bins
📏 Equal-Width
Each bin covers the same VALUE RANGE
Ages 0-100 → 10 bins of 10 years each:
[0-10], [10-20], ..., [90-100]
⚠️ Sensitive to outliers — one extreme value stretches all bins
📊 Equal-Depth (Quantile)
Each bin has the same NUMBER OF RECORDS
1000 people → 10 bins of 100 people each,
age ranges vary by data distribution
✅ Robust to outliers — extreme values just go in the last bin

Why Normalize?
Putting everything on the same scale
💰 Imagine comparing distances in miles vs meters. Or prices in dollars vs cents. If you don't convert them to the same unit, your analysis is dominated by the bigger numbers. Normalization is like converting to a common currency.

Problem: If age ranges 0–100 and salary ranges 0–100,000, then salary will dominate any distance calculation. A $10 salary difference will outweigh a 10-year age difference!

Min-Max Normalization
Squish everything into [0, 1]
📐 Imagine stretching or compressing a rubber band so it fits exactly between 0 and 1. The minimum value becomes 0, the maximum becomes 1, everything else scales proportionally.
x_norm = (x − min) / (max − min)

To map to a custom range [a, b]:

x_new = (x − min) / (max − min) × (b − a) + a
Original: 10–50Normalized: 0.0–1.0

📊 TRANSFORMATION • Card 23 of 30 FORMULA
📊
Z-Score Normalization
Standardization (μ=0, σ=1)
📏 "How unusual is this value?" A z-score tells you how many standard deviations away from average you are. A test score with z=2 means you scored 2 standard deviations above the class average — impressive!
z = (x − μ) / σ

μ = mean, σ = standard deviation

✅
Use When
Unknown min/max, or data follows a bell curve, or you want to detect outliers.
❌
Avoid When
You specifically need values in [0,1], or data has meaningful min/max (e.g., age, scores).
💡 Result After z-score normalization: mean = 0, std deviation = 1. Values are usually between -3 and +3.

Dimensionality Reduction
Finding the essence
📸 Imagine taking a 3D sculpture and photographing it from the BEST angle to capture the most detail in a 2D photo. PCA finds the "best viewing angle" for your data — reducing dimensions while keeping the most information.

If you have 100 measurements per customer, most are probably related (height and weight move together, salary and job title move together). PCA finds the most important directions.

100 dimensions → 3-5 key dimensions
while keeping ~95% of the information
💡 Why Reduce Dimensions? Faster algorithms, less storage, easier visualization (we can only see 2D/3D), and avoids the "curse of dimensionality."

👹 DIMENSIONALITY REDUCTION • Card 27 of 30 GOTCHA
👹
Curse of Dimensionality
Why high dimensions are dangerous
🌌 In 1D, 10 people can cover a street well. In 2D, you need 100 people to cover a city block. In 3D, 1000 people to cover a building. In 100D, you need more people than atoms in the universe to cover the space! Data becomes incredibly sparse.

As dimensions increase, distances lose meaning — all points appear equally far from each other. Nearest neighbor algorithms break down.

📍 1D
10 points cover the space well
📍 100D
Need 10¹⁰⁰ points to cover evenly!
💡 Solution Dimensionality reduction (PCA, feature selection) helps escape this curse by keeping only the most informative dimensions.

✂️ DIMENSIONALITY REDUCTION • Card 29 of 30 CONCEPT
✂️
Attribute Subset Selection
The simpler alternative to PCA
🗑️ Instead of doing complex math, just throw away the columns you don't need! If you're predicting heart disease, the column "favorite color" is probably irrelevant.

Attribute Subset Selection removes irrelevant or redundant attributes to reduce dimensionality without the math of PCA.

Irrelevant attributes: No relationship with the target. E.g., patient ID for disease prediction.
Redundant attributes: Carry the same info as another attribute. E.g., "Age" and "Birth Year" together.
Weakly relevant attributes: May help a little, but may also add noise.
💡 Methods Forward selection (add attributes one by one), backward elimination (remove one by one), stepwise selection (combination of both).

📚 Appendix: First Principles
d(A,B) = (Σ |xᵢ − yᵢ|ᵖ)^(1/p)
p = 1 → Manhattan Distance (L1)
p = 2 → Euclidean Distance (L2)
p → ∞ → Supremum Distance (L∞ = max |xᵢ−yᵢ|)

The Minkowski family unifies all common distance measures. The choice of p affects sensitivity to large differences.

KL(P||Q) = Σ P(x) · log(P(x)/Q(x))

Measures how much probability distribution P differs from reference distribution Q. Not a true distance (asymmetric: KL(P||Q) ≠ KL(Q||P)). Used in information theory and machine learning loss functions.

Step 1: Center data (subtract mean from each attribute).

Step 2: Compute the covariance matrix Σ (n×n matrix where Σᵢⱼ = cov(Xᵢ, Xⱼ)).

Σ = (1/m) · Xᵀ · X

Step 3: Find eigenvectors and eigenvalues of Σ.

Step 4: Sort eigenvectors by eigenvalue (descending). The eigenvector with the largest eigenvalue = first principal component.

Step 5: Project data onto top k eigenvectors. Each eigenvalue = variance explained by that PC.

r = Σ((xᵢ−x̄)(yᵢ−ȳ)) / (n·σₓ·σᵧ)

Range: [-1, 1]. r ≈ 1 means strong positive correlation (redundant). r ≈ -1 means strong negative correlation. r ≈ 0 means no linear relationship.

If two attributes have |r| > 0.9, one is likely redundant and can be removed in attribute subset selection.

Data Cleaning as a Two-Step Process:

Uniqueness Rule: Each value of the key/attribute must be unique across all tuples.
Consecutive Rule: No missing sequence numbers between minimum and maximum (e.g., check numbers, transaction serials).
Null Rule: Identifying suspicious blanks, question marks, and null placeholders (e.g., '01/01/1900', '9999').
Field Overloading: Occurs when developers squeeze new attribute definitions into unused portions of existing schemas.
Commercial Tools: Data Scrubbing (using domain rules & spell-checks) vs. Data Auditing (using correlation & clustering to find violators).
Potter's Wheel (VLDB 2001): An interactive, extensible framework that integrates discrepancy detection and transformation through a visual, spreadsheet-like interface.

Sorted Price Example: [4, 8, 9, 15, 21, 21, 24, 25, 26, 28, 29, 34]

Equal-Frequency (Equi-Depth) Bins of size 4: Bin 1: [4, 8, 9, 15] | Bin 2: [21, 21, 24, 25] | Bin 3: [26, 28, 29, 34]
Smoothing by Bin Means: Replace each bin value with bin average → Bin 1: [9, 9, 9, 9], Bin 2: [23, 23, 23, 23], Bin 3: [29, 29, 29, 29].
Smoothing by Bin Medians: Replace each bin value with its median value.
Smoothing by Bin Boundaries: Replace each value with its closest bin boundary (min or max) → Bin 1: [4, 4, 4, 15], Bin 2: [21, 21, 25, 25], Bin 3: [26, 26, 26, 34].
χ² = Σ Σ (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ

Algorithm Steps:

Sort numerical attribute values in ascending order and place each distinct value in its own interval.
For every pair of adjacent intervals, compute the Pearson χ² statistic measuring independence between the interval pair and the class labels.
Bottom-up merge the adjacent pair with the smallest χ² value (most similar class distributions).
Repeat recursively until all adjacent pairs have χ² exceeding a predefined stopping threshold.

Discrete Wavelet Transform (DWT):

S = [2, 2, 0, 2, 3, 5, 4, 4] → Ŝ = [2¾, −1¼, ½, 0, 0, −1, −1, 0]
Decomposes a signal/vector into multi-resolution frequency subbands using smoothing (averages) and difference (detail coefficients).
Lossless & Lossy Compression: Small detail coefficients near 0 are discarded, retaining only significant coefficients.
Properties: Preserves relative distances at varying resolutions, robust to noise and input order, uses hat-shaped filters, linear computational complexity $O(N)$.

Parametric Methods (Fit parameters, discard data):

Linear & Multiple Regression: $Y = wX + b$ or $Y = b_0 + b_1 X_1 + b_2 X_2$, parameters estimated by least squares.
Log-Linear Models: Approximates discrete multidimensional probability distributions in contingency tables based on smaller marginal subspaces.

Non-Parametric Methods: Histograms (equal-width, equal-frequency), Clustering, Sampling (SRSWOR, SRSWR, Stratified), and Data Cube Aggregation.

When data is linearly inseparable:

Kernel PCA (KPCA): Maps input data into a high-dimensional feature space using nonlinear kernels (Polynomial $\kappa(x_i, x_j) = (1 + x_i \cdot x_j)^p$ or Gaussian RBF $\kappa(x_i, x_j) = e^{-\|x_i - x_j\|^2 / (2\sigma^2)}$) before performing PCA.
Stochastic Neighbor Embedding (SNE & t-SNE): Converts pairwise Euclidean distances into conditional neighborhood probabilities $p_{j|i}$ and projects points into a low-dimensional space that minimizes the Kullback-Leibler (KL) divergence $\sum_i D_{KL}(P_i \parallel \hat{P}_i)$. t-SNE uses Student-t distribution in low-D space to prevent crowding.
