Chapter 1: Introduction to Data Analytics & KDD

~8 min read
📌 TL;DR (1-Minute Summary): Data Analytics transforms raw, unorganized numbers into high-value strategic wisdom through the 9-step KDD pipeline. Data mining is the automated discovery of non-trivial, hidden, previously unknown, and actionable patterns across 6 core tasks (characterization, discrimination, association, classification, clustering, outlier analysis).

1.1 The DIKW Pyramid (Data → Information → Knowledge → Wisdom)

💡 Real-World Analogy: Think of a patient monitoring device in an ICU:
  • • Data (Raw facts): Stream of raw integers: 140, 95, 142, 98.
  • • Information (Contextualized): Adding units and metadata: "Patient systolic/diastolic blood pressure is 140/95 mmHg at 10:00 AM."
  • • Knowledge (Pattern recognition): Connecting with medical rules: "Blood pressure above 140/90 mmHg consistently across 3 readings indicates Stage-2 Hypertension."
  • • Wisdom (Actionable decision): Clinical intervention: "Administer 5mg Amlodipine immediately to prevent cardiovascular crisis."

1.2 The 9-Step KDD Process (Knowledge Discovery in Databases)

Data mining is not an isolated trick; it is the central algorithmic core of the broader 9-stage engineering process:

1. Domain Understanding: Define user goals and prior knowledge.
2. Target Data Selection: Query relevant subsets from data warehouses.
3. Cleaning & Preprocessing: Remove noise, handle missing fields.
4. Data Reduction: Dimensionality reduction (PCA), feature selection.
5. Matching DM Goals: Decide task: classification, clustering, or rules.
6. Algorithm Choice: Select specific technique (e.g., C4.5, DBSCAN, Apriori).
7. Data Mining: Execute algorithms to uncover patterns.
8. Pattern Evaluation: Filter redundant rules using Lift/Kulczynski.
9. Knowledge Presentation: Visual dashboards and decision deployment.

1.3 The 6 Primary Data Mining Tasks

1. Characterization & Discrimination: Summarizing characteristics of a target class (e.g., software engineers who buy Macs) vs comparing against contrasting classes (e.g., non-buyers).
2. Association & Frequent Patterns: Finding items frequently bought together: $Beer \implies Diapers$ [Support 2%, Confidence 80%].
3. Classification (Supervised): Building a model on labeled training data to predict discrete categorical class labels for future items.
4. Cluster Analysis (Unsupervised): Grouping unlabeled objects based on maximizing intra-cluster similarity and minimizing inter-cluster similarity.
5. Outlier & Anomaly Analysis: Detecting observations that deviate so substantially from expected patterns as to indicate fraud, fault, or intrusion.
6. Trend & Evolution Analysis: Modeling time-series, spatio-temporal trajectories, and changing behavior across sequential periods.
⚠️ Professor's Exam Trap: Classification vs Clustering Never mix up Classification and Clustering! Classification is Supervised (target class labels exist in training data, e.g., Fraud = Yes/No). Clustering is Unsupervised (no target labels exist; the algorithm discovers clusters purely from pairwise distance metrics).

Chapter 2: Data Preprocessing, Measurements & Statistics

~18 min read
📌 TL;DR: Data preprocessing handles missing values, smooths noise, normalizes ranges, and reduces dimensions so distance-based classifiers can operate. The official Endsem syllabus explicitly requires solving Exercises 2.2, 2.7, 2.18, 2.19, and 2.20!

2.1 Attribute Measurement Hierarchy

Type Description Mathematical Operations Example
Nominal Categories, names, codes with no intrinsic order. =, ≠ (Mode only) Eye color, Marital status, Pin code
Ordinal Ranked sequence where relative order is meaningful, but distance between ranks is unknown. >, <, =, ≠ (Median, Percentiles) Grade (A, B, C), Shirt size (S, M, L), Customer satisfaction
Interval Equal scale intervals, but arbitrary zero point (0 does not mean absence!). +, − (Mean, StDev) Temperature in °C/°F, Calendar years (2026 AD)
Ratio Numeric scale with an inherent absolute zero point (0 means true absence). Ratios are valid! +, −, ×, ÷ (Geometric mean) Salary, Age, Weight, Temperature in Kelvin ($200K$ is twice $100K$)

2.2 Mathematical Distance & Similarity Metrics

Minkowski Distance ($L_p$ Norm): $$d(\vec{x}, \vec{y}) = \left(\sum_{i=1}^d |x_i - y_i|^p\right)^{1/p}$$

• $p=1$: Manhattan ($L_1$): City-block distance along grid lines.
• $p=2$: Euclidean ($L_2$): Straight-line ruler distance.
• $p=\infty$: Supremum ($L_\infty$): $\max_{i=1\dots d} |x_i - y_i|$.

Cosine Similarity (Document Vectors): $$\cos(\vec{x}, \vec{y}) = \frac{\vec{x} \cdot \vec{y}}{\|\vec{x}\| \|\vec{y}\|} = \frac{\sum x_i y_i}{\sqrt{\sum x_i^2}\sqrt{\sum y_i^2}}$$

Measures angle, not magnitude! If two documents discuss identical topics but one is 10× longer, their Euclidean distance is huge, but Cosine similarity is exactly 1.0!

Jaccard Coefficient (Binary Sets): $$J(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{q}{q + r + s}$$

$q$: attributes 1 in both; $r$: 1 in A, 0 in B; $s$: 0 in A, 1 in B. Ignores $t$ (0 in both) for asymmetric binary data!

Pearson Correlation Coefficient ($r_{A,B}$): $$r_{A,B} = \frac{\sum_{i=1}^n (a_i - \bar{A})(b_i - \bar{B})}{(n-1) s_A s_B} = \frac{\sum a_i b_i - n \bar{A}\bar{B}}{(n-1) s_A s_B}$$

Range $[-1, +1]$. $+1$: perfect positive linear correlation; $-1$: perfect negative; $0$: linearly uncorrelated.

2.3 Normalization Techniques

1. Min-Max Normalization: Maps to range $[\text{new\_min}, \text{new\_max}]$ (typically $[0, 1]$): $$v' = \frac{v - \min_A}{\max_A - \min_A} (\text{new\_max}_A - \text{new\_min}_A) + \text{new\_min}_A$$ Weakness: Extremely sensitive to future out-of-bounds outliers!
2. Z-Score Normalization (Zero-Mean): $$v' = \frac{v - \bar{A}}{\sigma_A} \quad \text{or with Mean Absolute Deviation: } v' = \frac{v - \bar{A}}{s_A}$$ Useful when actual min and max are unknown or outliers distort min-max bounds.
3. Decimal Scaling: $v' = \frac{v}{10^j}$, where $j$ is the smallest integer such that $\max(|v'|) < 1$.

Chapter 3: Data Warehousing, OLAP & BUC Algorithm

~15 min read
📌 TL;DR: A Data Warehouse is a subject-oriented, integrated, time-variant, non-volatile database optimized for complex analytical queries (OLAP). The BUC algorithm computes Iceberg Cubes bottom-up, recursively pruning entire lattice subtrees whenever tuple counts drop below min_sup. Mandated exercises: 3.15, 3.17, 3.18, 3.22.

3.1 Warehouse Architecture & Multidimensional Schemas

1. Star Schema

Single central Fact table referencing multiple un-normalized Dimension tables. Simplest query joins, fastest aggregations, high data redundancy.

2. Snowflake Schema

Dimension tables are normalized into hierarchies (e.g. Item → Subcategory → Category). Zero redundancy, but requires slower multi-table joins.

3. Fact Constellation

Multiple fact tables sharing common conformed dimension tables (e.g. Sales Fact and Shipping Fact sharing Item and Time dimensions).

3.2 OLAP Operations & Cube Measure Categories

5 Core OLAP Operations:

• Roll-Up: Climbing concept hierarchy (Day → Month → Year) or dimension reduction.

• Drill-Down: Stepping down hierarchy (Quarter → Month) or introducing new dimensions.

• Slice: Selecting a specific single value along one dimension (e.g. Time = '2026').

• Dice: Defining a subcube via conditions across 2+ dimensions.

• Pivot: Rotating 3D axes to provide alternative cross-tabulation perspectives.

3 Aggregation Measure Categories:

• Distributive: Computed by partitioning data, computing sub-aggregates, and combining directly: COUNT, SUM, MIN, MAX.

• Algebraic: Computed using algebraic functions over $M$ distributive measures: AVG = SUM / COUNT, STDDEV.

• Holistic: Cannot be computed from sub-aggregates; requires full dataset: MEDIAN, MODE, RANK.

3.3 The BUC Algorithm (Bottom-Up Computation, Beyer & Ramakrishnan 1999)

💡 Real-World Analogy: Imagine looking for big revenue branches in a multi-level organizational directory. Instead of checking every individual employee and aggregating upwards, you check the top division: if the entire "Footwear" division in Chicago sold only 3 pairs (below threshold 10), there is zero point checking running shoes, boots, or socks in that division! You prune the entire recursive tree immediately.
BUC Apriori Pruning Property:

$$\text{If } \text{count}(c) < \text{min\_sup}, \text{ then for any descendant cell } c' \supset c, \; \text{count}(c') \le \text{count}(c) < \text{min\_sup}$$

BUC explores cuboids bottom-up (1-D → 2-D → 3-D). It partitions data in memory and sorts dimensions in decreasing order of cardinality (dimensions with most unique values first) to maximize early pruning of sparse branches!

Chapter 4: Pattern Mining Basic Concepts & Methods

~15 min read
📌 TL;DR: Pattern mining discovers itemsets and rules that exceed minimum support and confidence thresholds. The Apriori algorithm generates candidates using downward closure ($L_{k-1} \bowtie L_{k-1}$); FP-Growth compresses the database into an FP-Tree to avoid candidate generation entirely. Mandated exercises: 4.3, 4.6, 4.10.

4.1 Core Definitions: Support, Confidence & Closed/Max Patterns

Support & Confidence: $$\text{Support}(A \implies B) = P(A \cup B) = \frac{\text{count}(A \cup B)}{N}$$ $$\text{Confidence}(A \implies B) = P(B|A) = \frac{\text{count}(A \cup B)}{\text{count}(A)}$$

A rule is strong if $\text{support} \ge \text{min\_sup}$ and $\text{confidence} \ge \text{min\_conf}$.

Closed vs Maximal Itemsets:

Closed Itemset: An itemset $X$ is closed if there exists no proper superset $Y \supset X$ with $\text{support}(Y) = \text{support}(X)$. (Lossless compression!)

Maximal Itemset: An itemset $X$ is maximal frequent if there exists no frequent proper superset $Y \supset X$. (Lossy compression: supports of sub-itemsets are lost).

4.2 Apriori vs FP-Growth Algorithm Comparison

Apriori Algorithm (Generate-and-Test):

• The Apriori Property: Any subset of a frequent itemset must also be frequent. (If $\{Bread\}$ is infrequent, then $\{Bread, Milk\}$ is guaranteed infrequent!).

• Join Step: $L_{k-1} \bowtie L_{k-1}$ on matching first $(k-2)$ items.

• Prune Step: Drop candidate $c \in C_k$ if any $(k-1)$ subset $\notin L_{k-1}$.

• Bottleneck: Multiple costly full-database scans ($k$ passes) and astronomical candidate explosion ($|C_2| = \binom{10^4}{2} \approx 5 \times 10^7$).

FP-Growth (Divide-and-Conquer):

• Scan 1: Find frequent 1-itemsets; sort items in descending order of frequency (F-List).

• Scan 2: Build FP-Tree by inserting each transaction ordered by F-List, sharing common prefixes with counter increments.

• Header Table: Linked-list pointers linking all nodes of the same item across branches.

• Mining: Bottom-up from rarest item: extract Conditional Pattern Base → build Conditional FP-Tree → mine recursively. Zero candidate generation!

Exercise 4.10: Lift vs Kulczynski vs Imbalance Ratio →

Problem: In a database of 10,000 transactions, 1,000 buy Coffee, 2,000 buy Tea, and 800 buy both. Compute Lift, Kulczynski ($Kulc$), and Imbalance Ratio ($IR$).

• $P(Coffee) = \frac{1000}{10000} = 0.10$
• $P(Tea) = \frac{2000}{10000} = 0.20$
• $P(Coffee \cap Tea) = \frac{800}{10000} = 0.08$

1. Lift:
$$\text{Lift}(Coffee \implies Tea) = \frac{P(Coffee \cap Tea)}{P(Coffee)P(Tea)} = \frac{0.08}{0.10 \times 0.20} = \frac{0.08}{0.02} = \mathbf{4.0}$$ Lift $= 4.0 > 1 \implies$ Coffee and Tea are strongly positively correlated!

2. Kulczynski Measure (Null-Invariant):
$$P(Tea|Coffee) = \frac{800}{1000} = 0.80, \quad P(Coffee|Tea) = \frac{800}{2000} = 0.40$$ $$\text{Kulc} = \frac{1}{2}(0.80 + 0.40) = \mathbf{0.60}$$ 3. Imbalance Ratio ($IR$):
$$IR = \frac{|P(Coffee) - P(Tea)|}{P(Coffee) + P(Tea) - P(Coffee \cap Tea)} = \frac{|0.10 - 0.20|}{0.10 + 0.20 - 0.08} = \frac{0.10}{0.22} \approx \mathbf{0.4545}$$

Chapter 5: Advanced Pattern Mining & 3 Mandated Papers

~15 min read
📌 TL;DR: Real-world data has hierarchies (Milk → Low-fat Milk), numeric measurements (Age: 20-30), and economic profit (a laptop yields more profit than 100 apples). Prof. Reddy's Endsem blueprint explicitly mandates 3 seminal research papers covering these exact domains!

5.1 The 3 Frontiers of Advanced Pattern Mining

Standard Apriori assumes flat, binary transactions with identical unit values. The 3 mandated research papers each solve a fundamental limitation:

PAPER 1: TAXONOMIES Multi-Level Rules (Han & Fu 1999)

Items belong to concept hierarchies. How do we mine rules across abstract and granular levels without getting drowned in redundant rules?

PAPER 2: NUMERIC RANGES Quantitative Rules (Srikant 1996)

Relational attributes are continuous numbers (e.g. Age, Income). How do we bin and combine intervals without losing information?

PAPER 3: ECONOMIC PROFIT High Utility (Liu et al. 2005)

Frequency ≠ Profit. How do we discover itemsets yielding high dollar margins using the two-phase TWU framework?

Paper 1: Mining Multiple-Level Association Rules in Large Databases (Han & Fu 1999)

Mandated Paper
💡 Real-World Analogy: At a supermarket, 80% of shoppers buy "Dairy Products" (Level 1), 30% buy "Milk" (Level 2), and only 1.5% buy "Dairyland 1% Low-fat Organic Milk" (Level 3). If you set a single high support threshold (10%), you miss the low-fat milk rule completely. If you set it to 1%, you generate 50,000 trivial rules at the top level!
1. Uniform Support vs. Reduced Support:

• Uniform Support: Same $\text{min\_sup}$ across all hierarchy levels. Fatal flaw: Low-level items have naturally lower frequencies and are pruned away.

• Reduced Support (Preferred): Progressive lower $\text{min\_sup}$ as depth increases (e.g., Level 1: 5%, Level 2: 2%, Level 3: 0.5%).

2. Redundant Rule Filtering Principle:

A rule $r': A' \implies B'$ at level $l$ is a specialization of rule $r: A \implies B$ at level $l-1$. Rule $r'$ is deemed redundant if its confidence and support do not significantly deviate from expectations derived from $r$:

$$\text{Confidence}(r') \approx \text{Confidence}(r) \quad \text{and} \quad \text{Support}(r') \approx \text{Support}(r) \times P(A'|A)$$

If "Milk → Bread" has 70% confidence, and "Lowfat Milk → Bread" also has 70% confidence, the low-fat rule provides zero new insight and is pruned!

Paper 2: Mining Quantitative Association Rules in Large Relational Tables (Srikant & Agrawal 1996)

Mandated Paper

Maps relational tuples containing categorical and continuous numeric fields into rules like: $\text{Age: } [30\dots 39] \land \text{Married: Yes} \implies \text{NumCars: } 2$ [Support 10%, Confidence 85%].

1. Equi-Depth Binning & Partial Completeness:

Partition numeric attributes into bins containing an equal number of tuples (equi-depth) rather than equal value ranges (equi-width). Prevents skew where dense regions are lumped together.

Partial Completeness: Guarantees that any rule with support $s$ and confidence $c$ will be discovered with support within a bounded distance $K$ of optimal intervals.

2. Minimum Win-Slack Heuristic:

Adjacent intervals are combined only if the combined interval provides substantially more support without dropping below minimum confidence. Prunes redundant sub-interval variants.

Paper 3: A Two-Phase Algorithm for Fast Discovery of High Utility Itemsets (Liu, Liao & Choudhary 2005)

Mandated Paper
💡 Real-World Analogy: Selling 100 bubblegums at 10 cents profit generates \$10. Selling 2 Rolex watches at \$5,000 profit generates \$10,000. Traditional Apriori ignores the price tag and declares bubblegum a "frequent itemset" while discarding the watches as "rare noise"! High-utility mining factors in the actual profit.
1. Utility Definitions:
• External Utility $p(i)$: Unit profit/value of item $i$ in utility table.
• Internal Utility $q(i, T)$: Quantity of item $i$ bought in transaction $T$.
• Utility of item in transaction: $u(i, T) = p(i) \times q(i, T)$.
• Transaction Utility: $TU(T) = \sum_{i \in T} u(i, T)$. Total dollar value of transaction $T$.
2. The Non-Monotonicity Problem:
Utility is NOT monotonic! A superset can have higher OR lower utility than its subsets. Hence, Apriori pruning cannot be applied directly to raw utility!
3. The TWU Downward Closure Breakthrough:
$$\text{Transaction-Weighted Utilization (TWU): } TWU(X) = \sum_{T \supseteq X} TU(T)$$

TWU Downward Closure Property: For any itemsets $X \subseteq Y$, we have $TWU(X) \ge TWU(Y)$. If $TWU(X) < \text{min\_util}$, then neither $X$ nor any of its supersets $Y$ can ever be high utility!

4. The Two-Phase Algorithm:
• Phase 1: Uses Apriori downward closure on $TWU$ to generate Candidate High Transaction-Weighted Utilization Itemsets (HTWUIs). (Over-generates, zero false negatives).
• Phase 2: Performs one database scan over raw transactions to compute the exact utility $u(X) = \sum_{T \supseteq X} u(X, T)$ for each candidate, filtering out those below $\text{min\_util}$.

6.1 Decision Tree Attribute Selection Measures

1. Information Gain (ID3): $$\text{Info}(D) = -\sum_{i=1}^m p_i \log_2(p_i)$$ $$\text{Info}_A(D) = \sum_{j=1}^v \frac{|D_j|}{|D|} \text{Info}(D_j)$$ $$\text{Gain}(D, A) = \text{Info}(D) - \text{Info}_A(D)$$

⚠️ Exam Trap: Biased toward attributes with many distinct values (e.g. Transaction_ID gives Gain = 1.0 but is useless)!

2. Gain Ratio (C4.5): $$\text{SplitInfo}_A(D) = -\sum_{j=1}^v \frac{|D_j|}{|D|} \log_2 \frac{|D_j|}{|D|}$$ $$\text{GainRatio}(D, A) = \frac{\text{Gain}(D, A)}{\text{SplitInfo}_A(D)}$$

Normalizes Information Gain by split entropy to penalize broad multi-valued attributes.

3. Gini Index (CART): $$\text{Gini}(D) = 1 - \sum_{i=1}^m p_i^2$$ $$\text{Gini}_A(D) = \frac{|D_1|}{|D|} \text{Gini}(D_1) + \frac{|D_2|}{|D|} \text{Gini}(D_2)$$ $$\Delta \text{Gini}(A) = \text{Gini}(D) - \text{Gini}_A(D)$$

Computes node impurity for binary splits. Minimizes misclassification impurity.

6.2 Naive Bayesian Classification & Laplace Smoothing

Bayes' Theorem: $$P(C_i|\mathbf{x}) = \frac{P(\mathbf{x}|C_i) P(C_i)}{P(\mathbf{x})}$$
Class-Conditional Independence Assumption: $$P(\mathbf{x}|C_i) = \prod_{k=1}^d P(x_k|C_i) = P(x_1|C_i) \times P(x_2|C_i) \times \dots \times P(x_d|C_i)$$
The Zero-Probability Problem & Laplace Correction:

If an attribute value $x_k$ never appeared with class $C_i$ in training data, $P(x_k|C_i) = 0$, which zeros out the entire product $P(\mathbf{x}|C_i) = 0$!

$$P_{\text{Laplace}}(x_k = v | C_i) = \frac{\text{count}(x_k=v, C_i) + 1}{\text{count}(C_i) + q}$$

Where $q$ is the total number of distinct possible values for attribute $x_k$.

Problem: Given a training set where attribute $A$ has 3 values $\{a_1, a_2, a_3\}$. In class $C_1$ (70 samples), counts are $a_1=50, a_2=20, a_3=0$. Show how Laplace correction avoids zero probability when classifying a sample with $A=a_3$.

7.1 Bayesian Belief Networks (BBN - Han §7.1)

While Naive Bayes assumes all attributes are mutually conditionally independent given the class, BBN allows specifying which subsets of attributes depend on each other.

Component 1: Directed Acyclic Graph (DAG) Nodes represent random variables; directed arcs represent probabilistic causal dependency. If there is no directed arc between $X$ and $Y$, they are conditionally independent given their parents!
Component 2: Conditional Probability Tables (CPT) For every node $X$, a table records the conditional distribution given all combinations of parent values: $P(X | \text{Parents}(X))$.
Joint Probability Factorization: $$P(x_1, x_2, \dots, x_n) = \prod_{i=1}^n P(x_i | \text{Parents}(X_i))$$

7.3 Support Vector Machines (SVM - Han §7.3)

💡 Real-World Analogy: Imagine building a straight highway dividing two enemy army camps. An amateur draws any line that doesn't hit a tent. An expert civil engineer builds the highway right down the middle with the widest possible cleared sidewalk (margin) on both sides. The tents right on the edge of the sidewalk are the Support Vectors.
1. Maximum Margin Hyperplane (MMH): Decision line: $\mathbf{w}^T \mathbf{x} + b = 0$. Margin width: $\gamma = \frac{2}{\|\mathbf{w}\|}$. To maximize margin width, we minimize $\|\mathbf{w}\| \implies \min \frac{1}{2}\|\mathbf{w}\|^2$ subject to $y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$.
2. The Kernel Trick for Non-Linear Boundaries:

If data is non-linearly separable in $\mathbb{R}^d$, map it via $\Phi(\mathbf{x})$ into a higher-dimensional Hilbert space $\mathcal{H}$ where a linear hyperplane exists. The Kernel Trick computes dot products directly in input space without ever calculating $\Phi(\mathbf{x})$ explicitly:

$$K(\mathbf{x}_i, \mathbf{x}_j) = \Phi(\mathbf{x}_i) \cdot \Phi(\mathbf{x}_j)$$ • Polynomial Kernel: $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z} + 1)^d$
• Gaussian Radial Basis Function (RBF): $K(\mathbf{x}, \mathbf{z}) = \exp\left(-\gamma \|\mathbf{x} - \mathbf{z}\|^2\right)$ (Infinite dimensional mapping!)

7.6 Ensemble Methods: Bagging, Boosting & Random Forests

Bagging (Bootstrap Aggregating) & Random Forests:

• Mechanism: Generate $B$ bootstrap samples (sampling with replacement, ~63.2% unique tuples). Train an independent base tree on each sample. Aggregate predictions via majority vote.

• Random Forest: Bagging + randomly select $k = \sqrt{d}$ candidate features at each node split to decorrelate trees.

• Goal: Drastically reduces variance without increasing bias!

Boosting (AdaBoost - Adaptive Boosting):

• Mechanism: Sequential training. In each round $t$, misclassified samples get increased weights $w_i \leftarrow w_i \exp(\alpha_t)$, while correct samples get decreased weights.

• Classifier Weight: $\alpha_t = \frac{1}{2} \ln\left(\frac{1 - \epsilon_t}{\epsilon_t}\right)$, where $\epsilon_t$ is weighted error.

• Goal: Converts weak learners into a strong learner; drastically reduces bias!

8.1 Partitioning Algorithms: K-Means vs PAM (K-Medoids)

K-Means (MacQueen 1967):

• Objective: Minimize Within-Cluster Sum of Squares (SSE):

$$\text{SSE} = \sum_{k=1}^K \sum_{\mathbf{x} \in C_k} \|\mathbf{x} - \mathbf{m}_k\|^2$$

• Algorithm: 1. Pick $k$ random centroids $\mathbf{m}_k$; 2. Assign each point to closest centroid; 3. Recompute centroid as mean of points; 4. Repeat until convergence.

⚠️ Exam Weaknesses: Sensitive to outliers (a single extreme point pulls the mean away); cannot discover non-spherical clusters; requires pre-specifying $k$.

PAM (Partitioning Around Medoids - Kaufman & Rousseeuw):

• Objective: Uses actual representative objects (medoids) instead of artificial centroids.

• Algorithm: Iteratively swaps a medoid $o_i$ with a non-medoid $o_h$ if the total swapping cost $TC_{ih} < 0$.

• Advantage: Extremely robust to noise and outliers!

• Complexity: $O(k(n-k)^2)$ per iteration. Infeasible for large datasets ($n > 1000$) $\implies$ solved by CLARA (sampling) and CLARANS (randomized graph search).

8.2 Hierarchical Linkage Criteria (AGNES)

1. Single Link (MIN): $$d(A, B) = \min_{\mathbf{p} \in A, \mathbf{q} \in B} d(\mathbf{p}, \mathbf{q})$$

Can handle non-elliptical shapes. Fatal weakness: Chaining effect (noisy noise points act as bridges merging separate clusters!).

2. Complete Link (MAX): $$d(A, B) = \max_{\mathbf{p} \in A, \mathbf{q} \in B} d(\mathbf{p}, \mathbf{q})$$

Produces tight, compact spherical clusters; avoids chaining. Weakness: Highly sensitive to outliers.

3. Average Link (Mean): $$d(A, B) = \frac{1}{|A||B|} \sum_{\mathbf{p} \in A} \sum_{\mathbf{q} \in B} d(\mathbf{p}, \mathbf{q})$$

Robust compromise between single and complete link; less sensitive to noise.

4. Ward's Method: $$\Delta ESS(A, B) = \frac{|A||B|}{|A| + |B|} \|\mathbf{m}_A - \mathbf{m}_B\|^2$$

Merges clusters minimizing the increase in total within-cluster variance.

8.3 Cluster Validation: The Silhouette Coefficient

For each object $i$, define:

• $a(i)$: Average dissimilarity of $i$ to all other objects in its own cluster (cohesion).

• $b(i)$: Minimum average dissimilarity of $i$ to all objects in any other cluster (separation).

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}, \quad -1 \le s(i) \le +1$$

• $s(i) \approx +1$: Point is tightly clustered with its peers and far from other clusters (✓ Excellent!).

• $s(i) \approx 0$: Point lies on the border between two clusters.

• $s(i) \approx -1$: Point has been misclassified into the wrong cluster!

CLARANS, BIRCH, DBSCAN, CHAMELEON
Paper 4: CLARANS: A Method for Clustering Objects for Spatial Data Mining (Ng & Han 1994) →

Core Innovation: Views the medoid clustering search space as an abstract graph $G_n^k$, where each vertex is a set of $k$ medoids, and two vertices are connected if they differ by exactly 1 medoid.

  • PAM checks all $k(n-k)$ neighbors (exhaustive local search → slow).
  • CLARA draws multiple small samples of size $40 + 2k$ and runs PAM (biased toward sample).
  • CLARANS (Randomized Search): Explores the full graph dynamically by inspecting at most maxneighbor randomly chosen neighbors. If an improvement is found, move to that vertex. If no improvement is found in maxneighbor checks, record local minimum and restart with a fresh random vertex up to numlocal times!
  • Result: Superior quality over CLARA with significantly faster runtime than PAM.
Paper 5: BIRCH: An Efficient Data Clustering Method for Very Large Databases (Zhang et al. 1996) →

Core Innovation: Overcomes I/O bottlenecks by summarizing dense clusters into in-memory Clustering Feature (CF) vectors stored in a height-balanced CF-Tree.

$$CF = (N, \vec{LS}, SS)$$ • $N$: Number of data points.
• $\vec{LS} = \sum_{i=1}^N \mathbf{x}_i$: Linear sum of $N$ points.
• $SS = \sum_{i=1}^N \mathbf{x}_i^2$: Square sum of $N$ points.
• CF Additivity Property: If cluster $C_1$ has $CF_1$ and $C_2$ has $CF_2$, the merged cluster $C_1 \cup C_2$ has $CF = CF_1 + CF_2 = (N_1 + N_2, \vec{LS}_1 + \vec{LS}_2, SS_1 + SS_2)$ without needing raw points!

4-Phase Architecture: Phase 1: Build in-memory CF-tree; Phase 2: Condense tree; Phase 3: Run global clustering (e.g. agglomerative) on leaf entries; Phase 4: Reassign raw data tuples.

Paper 6: DBSCAN: A Density-Based Algorithm for Discovering Clusters (Ester et al. 1996) →

Core Innovation: Discovers clusters of arbitrary non-spherical shapes (e.g. rings, S-shapes) and isolates noise points without requiring $k$ in advance.

• $\epsilon$-Neighborhood: $N_\epsilon(p) = \{q \in D \mid \text{dist}(p, q) \le \epsilon\}$.
• Core Point: Point $p$ having $|N_\epsilon(p)| \ge MinPts$.
• Border Point: Not a core point, but falls inside the $\epsilon$-neighborhood of a core point.
• Noise Point: Neither a core nor a border point.
• Directly Density-Reachable: Point $q$ is directly density-reachable from $p$ if $p$ is a core point and $q \in N_\epsilon(p)$.
• Density-Reachable: Chain of directly reachable core points $p_1 \to p_2 \to \dots \to q$. (Transitive, but asymmetric!).
• Density-Connected: Both $p$ and $q$ are density-reachable from a common core point $o$. (Symmetric and reflexive).
Paper 7: CHAMELEON: A Hierarchical Clustering Algorithm Using Dynamic Modeling (Karypis et al. 1999) →

Core Innovation: Dynamic modeling of cluster similarity that adapts to the internal characteristics of the clusters being merged (unlike CURE or ROCK which use static models).

• Phase 1: Construct a $k$-NN graph from data points and partition it into thousands of small, highly cohesive subclusters using a multilevel graph partitioning algorithm (hMETIS).
• Phase 2: Agglomerative merging of subclusters based on two dynamic metrics:
  1. Relative Interconnectivity ($RI$): Ratio of edge-cut between clusters $C_i, C_j$ to internal edge-cuts within $C_i$ and $C_j$: $$RI(C_i, C_j) = \frac{2 |EC_{\{C_i, C_j\}}|}{|EC_{C_i}| + |EC_{C_j}|}$$   2. Relative Closeness ($RC$): Ratio of average weight of crossing edges to internal average edge weights: $$RC(C_i, C_j) = \frac{\bar{S}_{EC_{\{C_i, C_j\}}}}{\frac{|C_i|}{|C_i|+|C_j|}\bar{S}_{EC_{C_i}} + \frac{|C_j|}{|C_i|+|C_j|}\bar{S}_{EC_{C_j}}}$$ • Decision Rule: Merge subclusters only if both $RI$ and $RC$ are high ($RI \times RC^\alpha \ge \text{threshold}$).

9.1 The Perceptron Model & The XOR Barrier

The Perceptron (Rosenblatt 1958):

• Net Input: $z = \mathbf{w}^T \mathbf{x} + b = \sum_{i=1}^d w_i x_i + b$.

• Step Activation: $y = +1$ if $z \ge 0$, else $-1$ (or 0).

• Learning Rule: $\mathbf{w} \leftarrow \mathbf{w} + \eta (t - y) \mathbf{x}$, where $\eta \in (0, 1]$ is learning rate.

• Convergence Theorem (Novikoff 1962): Converges in finite steps if and only if data is linearly separable.

The XOR Barrier (Minsky & Papert 1969):

• In XOR: $(0, 0) \to 0, (1, 1) \to 0$, but $(0, 1) \to 1, (1, 0) \to 1$.

• Points with label 1 lie on the opposite diagonal of points with label 0. No single straight line can separate them!

• Solution (MLP): Adding a hidden layer with 2 neurons (one computing OR, one computing NAND) transforms the space so the output neuron (computing AND) linearly separates them!

9.2 Activation Functions & Derivatives

1. Logistic Sigmoid $\sigma(z)$: $$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z))$$

Range $(0, 1)$. Max derivative is $0.25$ at $z=0$. Causes severe vanishing gradient in deep layers!

2. Hyperbolic Tangent $\tanh(z)$: $$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}, \quad \tanh'(z) = 1 - \tanh^2(z)$$

Range $(-1, +1)$. Zero-centered, speeding up convergence over sigmoid.

3. Rectified Linear Unit (ReLU): $$f(z) = \max(0, z), \quad f'(z) = \begin{cases} 1 & z > 0 \\ 0 & z < 0 \end{cases}$$

Modern standard. Constant derivative of 1 stops gradient vanishing completely!

9.3 The Backpropagation Chain Rule Formulation

1. Output Layer Weight Gradient ($w_{jk}$ connecting hidden node $j$ to output $k$): $$\frac{\partial E}{\partial w_{jk}} = \frac{\partial E}{\partial z_k} \frac{\partial z_k}{\partial w_{jk}} = \delta_k \cdot a_j, \quad \text{where } \delta_k \equiv (a_k - t_k) \sigma'(z_k)$$
2. Hidden Layer Weight Gradient ($w_{ij}$ connecting input $i$ to hidden node $j$): $$\frac{\partial E}{\partial w_{ij}} = \frac{\partial E}{\partial z_j} \frac{\partial z_j}{\partial w_{ij}} = \delta_j \cdot x_i, \quad \text{where } \delta_j \equiv \left(\sum_k \delta_k w_{jk}\right) \sigma'(z_j)$$
3. Parameter Updates: $$w \leftarrow w - \eta \frac{\partial E}{\partial w}, \quad b \leftarrow b - \eta \delta$$

10.1 Advanced Clustering Paradigms

1. STING (Grid-Based):

Hierarchical quad-tree cells storing precomputed statistics ($n, m, s, \min, \max, \text{dist}$). Query processing traverses cells top-down in $O(K)$ time, completely independent of the number of raw data tuples $N$!

2. CLIQUE (Subspace):

Finds clusters in arbitrary subspaces of high-dimensional data. Uses the Apriori Subspace Principle: A $k$-dimensional cell is dense ONLY IF all its $(k-1)$-dimensional projections are dense.

3. DENCLUE (Kernel Density):

Models data using non-parametric Gaussian influence kernels. Finds local density peaks (density attractors) using gradient hill climbing. Highly resilient to noise.

10.2 Outlier Analysis: Hawkins Definition & The 3 Classes

💡 Hawkins (1980) Definition: "An outlier is an observation which deviates so much from other observations as to arouse suspicions that it was generated by a different mechanism."
1. Global Outlier: Deviates significantly relative to the entire dataset (e.g. Bill Gates' net worth in an ordinary neighborhood income survey).
2. Contextual Outlier: Deviates with respect to a context (e.g. 35°C in Hyderabad in May is normal, but 35°C in late December is a contextual anomaly).
3. Collective Outlier: A sequence of points that collectively deviate (e.g. flatline cardiac ECG for 3 seconds, where voltage values are normal individually).

10.3 Local Outlier Factor (LOF - Breunig et al. SIGMOD 2000)

⚠️ Why Distance-Based Detection ($k$-NN Distance) Fails: In datasets with clusters of different densities, legitimate inliers in a sparse cluster have larger Euclidean distance to their $k$-NN than genuine outliers floating outside a dense cluster! LOF fixes this by comparing relative local density ratios.
1. Reachability Distance: $$\text{reach-dist}_k(p, o) = \max\{d_k(o), d(p, o)\}$$
2. Local Reachability Density ($\text{lrd}_k(p)$): $$\text{lrd}_k(p) = \frac{|N_k(p)|}{\sum_{o \in N_k(p)} \text{reach-dist}_k(p, o)}$$
3. Local Outlier Factor ($\text{LOF}_k(p)$): $$\text{LOF}_k(p) = \frac{\sum_{o \in N_k(p)} \frac{\text{lrd}_k(o)}{\text{lrd}_k(p)}}{|N_k(p)|}$$

• $\text{LOF} \approx 1.0$: Inlier (density matches neighbors). • $\text{LOF} \gg 1.0$: Outlier (density is much lower than neighbors!).

Worked Numerical Example: 1D LOF Calculation ($k=2$)

Points on 1D line: $A=0, B=1, C=2, P=6$. Compute $\text{LOF}_2(P)$.

• $d_2(A)=2, N_2(A)=\{B,C\}$; $d_2(B)=1, N_2(B)=\{A,C\}$; $d_2(C)=2, N_2(C)=\{B,A\}$; $d_2(P)=5, N_2(P)=\{C,B\}$.
• $\text{reach-dist}_2(P, C) = \max\{d_2(C), d(P,C)\} = \max\{2, 4\} = 4$.
• $\text{reach-dist}_2(P, B) = \max\{d_2(B), d(P,B)\} = \max\{1, 5\} = 5$.
• $\text{lrd}_2(B) = \frac{2}{1+1} = 1.0$; $\text{lrd}_2(C) = \frac{2}{2+2} = 0.5$; $\text{lrd}_2(P) = \frac{2}{4+5} = \frac{2}{9} \approx 0.2222$.
$$\text{LOF}_2(P) = \frac{\frac{\text{lrd}_2(C)}{\text{lrd}_2(P)} + \frac{\text{lrd}_2(B)}{\text{lrd}_2(P)}}{2} = \frac{\frac{0.5}{2/9} + \frac{1.0}{2/9}}{2} = \frac{2.25 + 4.5}{2} = \mathbf{3.375}$$ Since $\text{LOF}_2(P) = 3.375 \gg 1.0$, $P$ is decisively identified as an outlier!

10.4 Emerging Trends in Data Mining

1. Spatio-Temporal Trajectory Mining:

• Tobler's First Law: "Near things are more related than distant things" (spatial autocorrelation breaks i.i.d. assumption!).

• Convoy vs Swarm: A Convoy requires $m$ objects to travel together for $k$ consecutive timestamps; a Swarm relaxes this to $k$ non-consecutive timestamps.

2. High-Dimensional Empty Space Phenomenon:

• Distance Concentration (Beyer et al. 1999): $\lim_{d\to\infty} \frac{d_{\max} - d_{\min}}{d_{\min}} = 0$. In high dimensions, every point becomes virtually equidistant from every other point!

• Empty Space: The volume of a hypersphere of radius $r$ inside a hypercube approaches 0 as $d \to \infty$. All mass concentrates in outer corners.
