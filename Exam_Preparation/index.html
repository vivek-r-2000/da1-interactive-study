Scientific Calculator Operational Guide

Prof. Reddy officially noted that scientific calculators are permitted. Make sure you utilize these operations efficiently during numerical questions:

  • • Logarithm Base 2: Compute $\log_2(p) = \frac{\ln(p)}{\ln(2)}$ or $\frac{\log_{10}(p)}{\log_{10}(2)}$. Do not round intermediate logs!
  • • Entropy Accumulator: Store parent $Info(D)$ in memory register `M+`. Compute each partition $Info(D_j)$ and sum weighted proportions directly.
  • • Chi-Square $(\chi^2)$: Calculate expected frequencies $E_{ij} = \frac{R_i \times C_j}{N}$ using two-variable statistics or fraction operations.
  • • Vector Norms in SVM: Use Pythagoras or polar conversions to compute $\|\vec{w}\| = \sqrt{w_1^2 + w_2^2}$ for margin $\frac{2}{\|\vec{w}\|}$.

Exercise 2.2 — Central Tendency, Quartiles & Boxplot (Book p. 80 / PDF p. 111) Chapter 2: Data & Preprocessing
Verbatim Problem: Suppose that the data for analysis include the attribute age. The age values for the data tuples are (in ascending order): 13, 15, 16, 16, 19, 20, 20, 21, 22, 22, 25, 25, 25, 25, 30, 33, 33, 35, 35, 35, 35, 36, 40, 45, 46, 52, 70. (a) What is the mean of the data? What is the median? (b) What is the mode of the data? Comment on the data's modality. (c) What is the midrange of the data? (d) Can you find (roughly) the first quartile ($Q_1$) and third quartile ($Q_3$)? (e) Give the five-number summary. (f) Show a boxplot of the data.

Verified Solution ($N = 27$):

  • (a) Mean & Median: $\sum x_i = 809 \implies \bar{x} = \frac{809}{27} \approx \mathbf{29.9630}$. Since $N=27$ is odd, median position is $\frac{27+1}{2}=14 \implies \text{Median} = x_{(14)} = \mathbf{25}$.
  • (b) Mode & Modality: Both $25$ and $35$ occur $4$ times (max frequency). Hence the dataset is bimodal (modes: $25, 35$).
  • (c) Midrange: $\frac{\min + \max}{2} = \frac{13 + 70}{2} = \mathbf{41.5}$.
  • (d) Quartiles ($Q_1, Q_3$): Splitting at median $x_{(14)}=25$ leaves $13$ items in lower half (middle $7$th item is $Q_1 = \mathbf{20}$) and $13$ items in upper half ($15$th–$27$th; middle $21$st item is $Q_3 = \mathbf{35}$).
  • (e) Five-Number Summary: $[\min, Q_1, \text{median}, Q_3, \max] = \mathbf{[13, 20, 25, 35, 70]}$.
  • (f) Boxplot & Fences: $\text{IQR} = Q_3 - Q_1 = 35 - 20 = 15$. Upper fence $= Q_3 + 1.5\cdot\text{IQR} = 35 + 22.5 = 57.5$; lower fence $= 20 - 22.5 = -2.5$. Since $70 \gt 57.5$, $70$ is an outlier (plotted individually); lower whisker $= 13$, box $= [20, 35]$ (median $25$), upper whisker $= \mathbf{52}$.

Exercise 2.18 — Normalizing Age = 35 Using Ex. 2.14 Data (Book p. 82 / PDF p. 113) Chapter 2: Data & Preprocessing
Verbatim Problem: Using the data for age given in Exercise 2.14 (13, 15, 16, 16, 19, 20, 20, 21, 22, 22, 25, 25, 25, 25, 30, 33, 33, 35, 35, 35, 35, 36, 40, 45, 46, 52, 70; $N=27, \min=13, \max=70, \bar{x}=\frac{809}{27}\approx 29.9630$), answer: (a) Use min-max normalization to transform $35$ onto $[0.0, 1.0]$. (b) Use z-score normalization to transform $35$, where standard deviation $\sigma = 12.70$ years. (c) Use normalization by decimal scaling to transform $35$. (d) Comment on which method you prefer and why.
(a) Min-Max Normalization onto $[0.0, 1.0]$: $$v' = \frac{v - \min_A}{\max_A - \min_A}(1.0 - 0.0) + 0.0 = \frac{35 - 13}{70 - 13} = \frac{22}{57} \approx \mathbf{0.3860}$$
(b) Z-Score Normalization ($\sigma = 12.70$ years): $$v' = \frac{v - \bar{A}}{\sigma_A} = \frac{35 - 29.9630}{12.70} = \frac{5.0370}{12.70} \approx \mathbf{0.3966}$$ (Using rounded $\bar{A}=29.96$ gives $\frac{5.04}{12.70}\approx 0.3969$.)
(c) Decimal Scaling Normalization: $\max(|v_i|) = 70 \implies$ smallest integer $j$ with $\frac{70}{10^j} \lt 1$ is $j = 2$ ($10^2 = 100$): $$v' = \frac{35}{10^2} = \mathbf{0.35}$$
(d) Preferred Method: Decimal scaling (or z-score) is preferred over min-max here: decimal scaling divides by $100$, preserves exact proportions, requires no statistics, and stays within $[0,1)$ for any human age $\lt 100$. Z-score also prevents range compression caused by the extreme outlier $70$ and avoids out-of-bounds failures on future records $\gt 70$.

Exercise 3.17 — Max & Min Cells in an n-D Data Cube (Book p. 138 / PDF p. 169) Chapter 3: Data Warehousing & OLAP
Verbatim Problem: A data cube, $C$, has $n$ dimensions, and each dimension has exactly $p$ distinct values in the base cuboid. Assume that there are no concept hierarchies associated with the dimensions. (a) Max cells in base cuboid? (b) Min cells in base cuboid? (c) Max cells (base + aggregate) in $C$? (d) Min cells in $C$?
  • (a) Max Base Cells: Every combination in Cartesian product is present $\implies \mathbf{p^n}$.
  • (b) Min Base Cells: Since each dimension must contain all $p$ distinct values, placing them diagonally $(v_{1,i}, \dots, v_{n,i})$ achieves the minimum $\mathbf{p}$.
  • (c) Max Total Cells in $C$: Each coordinate has $p$ values plus $*$ (all) $\implies \sum_{k=0}^n \binom{n}{k} p^k = \mathbf{(p + 1)^n}$.
  • (d) Min Total Cells in $C$: Of the $2^n$ cuboids, the $0$-D apex has $1$ cell, and each of the $2^n - 1$ non-apex cuboids retains $\ge 1$ dimension having $p$ distinct values ($\ge p$ cells, attained by $p$ diagonal base cells) $\implies \mathbf{p(2^n - 1) + 1 = p \cdot 2^n - p + 1}$.
Exercise 3.18 — 10-D Base Cuboid (3 Cells): Full, Iceberg & Closed Cube (Book p. 138 / PDF p. 169) Chapter 3: Data Warehousing & OLAP
Verbatim Problem: A 10-D base cuboid has 3 base cells: (1) $(a_1, d_2, d_3, d_4, \dots, d_{10})$, (2) $(d_1, b_2, d_3, d_4, \dots, d_{10})$, (3) $(d_1, d_2, c_3, d_4, \dots, d_{10})$, where $a_1 \ne d_1, b_2 \ne d_2, c_3 \ne d_3$ and measure is count(). Find: (a) nonempty cuboids in full cube, (b) nonempty aggregate (nonbase) cells in full cube, (c) nonempty aggregate cells in iceberg cube ($\text{count} \ge 2$), (d) closed cells in full cube.

Dimensions $F = \{4,\dots,10\}$ never differ across the 3 cells, giving $2^7 = 128$ keep/$*$ subsets $S_F$.

  • (a) Nonempty Cuboids: Every projection of a nonempty base cuboid is nonempty $\implies 2^{10} = \mathbf{1024}$.
  • (b) Nonempty Aggregate (Nonbase) Cells: Over $S_V \subseteq \{1,2,3\}$: $\emptyset \to 1$ cell (count 3); $|S_V|=1$ ($3$ cuboids) $\to 2$ cells each (count 2 and 1); $|S_V|=2$ ($3$ cuboids) $\to 3$ cells each (count 1); $S_V=\{1,2,3\} \to 3$ cells across $127$ nonbase cuboids (excluding the 10-D base cuboid). Sum $= (1 + 6 + 9)\times 128 + 3 \times 127 = \mathbf{2429}$ (total $2432 - 3$ base).
  • (c) Iceberg Aggregate Cells ($\text{count} \ge 2$): Only $S_V=\emptyset$ ($1$ cell, count 3) and $|S_V|=1$ ($3 \times 1$ cells having $d_i$, count 2) pass $\implies (1 + 3)\times 128 = \mathbf{512}$.
  • (d) Closed Cells: Every closed cell fixes $d_4,\dots,d_{10}$ (otherwise specializing $*$ to $d_k$ preserves count): count 3 gives $(*,*,*,d_4\dots)$ ($1$ cell); count 2 gives $(d_1,*,*), (*,d_2,*), (*,*,d_3)$ ($3$ cells); count 1 gives the $3$ base cells $\implies 1 + 3 + 3 = \mathbf{7}$.

Verbatim Problem: Two 100-D base cells: $(a_1, a_2, a_3, \dots, a_{100})$ and $(a_1, a_2, b_3, \dots, b_{100})$. (a) Compute number of nonempty aggregate cells; comment on space and time. Exercise 4.1 — Querying Frequent Closed Itemsets $\mathcal{C}$ (Book p. 170 / PDF p. 201) Chapter 4: Basic Pattern Mining (Moodle "4.1Chapter 5" Check)
Verbatim Problem: Suppose you have the set $\mathcal{C}$ of all frequent closed itemsets on a data set $D$, as well as the support count for each frequent closed itemset. Describe an algorithm to determine whether a given itemset $X$ is frequent or not, and the support of $X$ if it is frequent.
  1. Find all frequent closed supersets of $X$: $S = \{Y \in \mathcal{C} \mid X \subseteq Y\}$.
  2. If $S = \emptyset$, return not frequent (because $\text{closure}(X)$ has the same support as $X$, so if $X$ were frequent then $\text{closure}(X) \in \mathcal{C}$ would cover $X$).
  3. Otherwise ($S \ne \emptyset$), return frequent with exact support $\text{support\_count}(X) = \max_{Y \in S} \text{support\_count}(Y)$ (achieved at $Y = \text{closure}(X)$).
Exercise 4.3 — Apriori Subset Support, Confidence & Partition Proofs (Book p. 170 / PDF p. 201) Chapter 4: Basic Pattern Mining
Verbatim Problem: The Apriori algorithm makes use of prior knowledge of subset support properties. (a) Prove all nonempty subsets of a frequent itemset must be frequent. (b) Prove $\text{support}(s') \ge \text{support}(s)$ for any nonempty subset $s'$ of $s$. (c) Given frequent itemset $l$ and $s \subset l, s' \subseteq s$, prove $\text{conf}(s' \Rightarrow (l - s')) \le \text{conf}(s \Rightarrow (l - s))$. (d) If $D$ is subdivided into $n$ nonoverlapping partitions, prove any itemset frequent in $D$ must be frequent in at least one partition.
  • (a) & (b): For any nonempty $s' \subseteq s$, every transaction $T \in D$ containing $s$ must also contain $s'$: $\{T \mid s \subseteq T\} \subseteq \{T \mid s' \subseteq T\} \implies \text{sup\_count}(s') \ge \text{sup\_count}(s) \implies \text{support}(s') \ge \text{support}(s)$. Thus if $s$ is frequent ($\ge \text{min\_sup}$), all nonempty subsets $s'$ are frequent.
  • (c): $\text{conf}(s' \Rightarrow (l-s')) = \frac{\text{sup}(l)}{\text{sup}(s')}$ and $\text{conf}(s \Rightarrow (l-s)) = \frac{\text{sup}(l)}{\text{sup}(s)}$. Since $s' \subseteq s$, by (b) $\text{sup}(s') \ge \text{sup}(s) \ge \text{sup}(l) \gt 0$, so taking reciprocals reverses the inequality: $\text{conf}(s' \Rightarrow (l-s')) \le \text{conf}(s \Rightarrow (l-s))$.
  • (d) Partition Proof (by contradiction): Suppose $X$ is frequent in $D$ ($\text{sup\_count}_D(X) \ge \sigma |D|$) yet infrequent in every partition $D_i$: $\text{sup\_count}_{D_i}(X) \lt \sigma |D_i|$ for $i=1\dots n$. Summing gives $\text{sup\_count}_D(X) = \sum_{i=1}^n \text{sup\_count}_{D_i}(X) \lt \sigma \sum_{i=1}^n |D_i| = \sigma |D|$, a contradiction.
Exercise 4.6 — MONKEY Database: Apriori vs FP-Growth & Strong Metarules (Book p. 171 / PDF p. 202) Chapter 4: Basic Pattern Mining
Verbatim Problem: A database has five transactions ($\text{min\_sup} = 60\% \implies \text{count} \ge 3$, $\text{min\_conf} = 80\%$): T100: {M, O, N, K, E, Y}, T200: {D, O, N, K, E, Y}, T300: {M, A, K, E}, T400: {M, U, C, K, Y}, T500: {C, O, O, K, I, E} (as distinct set of items: {C, O, K, I, E}). (a) Find all frequent itemsets using Apriori and FP-growth, and compare efficiency. (b) List all strong association rules matching $\forall x \in \text{transaction},\; \text{buys}(X, \text{item}_1) \land \text{buys}(X, \text{item}_2) \Rightarrow \text{buys}(X, \text{item}_3)\; [s, c]$.
(a1) Apriori (3 DB scans, 22 candidates counted + 3 pruned):
  • $L_1$ ($\text{sup} \ge 3$): {E}:4, {K}:5, {M}:3, {O}:3, {Y}:3.
  • $L_2$ (out of $\binom{5}{2}=10$ candidates in $C_2$): {E,K}:4, {E,O}:3, {K,M}:3, {K,O}:3, {K,Y}:3.
  • $C_3 \to L_3$: Raw join produces {E,K,O} (kept), plus {K,M,O}, {K,M,Y}, {K,O,Y} (all 3 pruned since {M,O}, {M,Y}, {O,Y} $\notin L_2$). Hence $L_3 = \{\{E,K,O\}:3\}$. Total = 11 frequent itemsets.
(a2) FP-Growth (2 DB scans, zero candidate generation): F-list: K:5, E:4, M:3, O:3, Y:3. Ordered DB: KEMOY, KEOY, KEM, KMY, KEO. Root splits into K:5 → E:4 → (M:2 → O:1 → Y:1, O:2 → Y:1) and K:5 → M:1 → Y:1. Conditional mining from bottom up yields identical 11 frequent itemsets (faster on dense data; avoids multi-pass DB I/O and combinatorial $C_k$ joins).
(b) Strong Rules Matching $2 \Rightarrow 1$ Metarule (from $L_3 = \{E, K, O\}$, $s = 3/5 = 60\%$):
  • $E \land K \Rightarrow O$: $\text{conf} = 3/4 = 75\%$ (Reject, $\lt 80\%$).
  • $\mathbf{E \land O \Rightarrow K}$: $s = 60\%, c = 3/3 = \mathbf{100\%}$ (Strong).
  • $\mathbf{K \land O \Rightarrow E}$: $s = 60\%, c = 3/3 = \mathbf{100\%}$ (Strong).
Exercise 4.10 — Incremental Mining on $DB \cup \Delta DB$ (Book p. 172 / PDF p. 203) Chapter 4: Basic Pattern Mining
Verbatim Problem: Suppose that frequent itemsets are saved for a large transactional database, $DB$. Discuss how to efficiently mine the (global) association rules under the same minimum support threshold, if a set of new transactions, denoted as $\Delta DB$, is (incrementally) added in?

An itemset $X$ is globally frequent in $DB' = DB \cup \Delta DB$ iff $\text{sup\_count}_{DB}(X) + \text{sup\_count}_{\Delta DB}(X) \ge \sigma(|DB| + |\Delta DB|)$. By Exercise 4.3(d), any globally frequent itemset must be frequent in $DB$ ($L^{DB}$) or $\Delta DB$ ($L^{\Delta DB}$) — the FUP Incremental Mining Strategy:

  • Case 1 ($X \in L^{DB}, X \in L^{\Delta DB}$): Automatically globally frequent; sum counts directly (zero $DB$ scan).
  • Case 2 ($X \in L^{DB}, X \notin L^{\Delta DB}$): Scan small $\Delta DB$ only; if sum $\lt \sigma(|DB|+|\Delta DB|)$, prune loser $X$ and its supersets (zero $DB$ scan).
  • Case 3 ($X \notin L^{DB}, X \in L^{\Delta DB}$): Potential new winner; filter by global $(k-1)$-subset Apriori check, then scan $DB$ only for these surviving candidates.
  • Case 4 ($X \notin L^{DB}, X \notin L^{\Delta DB}$): Guaranteed infrequent in $DB'$; pruned immediately. Strong rules are then extracted in memory from updated $L^{DB'}$.

Exercise 6.19 — 10-Fold Cross-Validation Paired $t$-Test (Book p. 302 / PDF p. 333) Chapter 6: Classification Basic
Verbatim Problem: Suppose we want to select between two prediction models, $M_1$ and $M_2$, using 10 rounds of 10-fold CV. The error rates for $M_1$ are 30.5, 32.2, 20.7, 20.6, 31.0, 41.0, 27.7, 26.0, 21.5, 26.0. The error rates for $M_2$ are 22.4, 14.5, 22.4, 19.6, 20.7, 20.4, 22.1, 19.4, 16.2, 35.0. Comment on whether one model is significantly better than the other at significance level $1\%$.

Step-by-Step Paired $t$-Test (Han Eq. 6.31–6.32, Book pp. 285–286):

• Differences $d_i = \text{err}(M_1)_i - \text{err}(M_2)_i$: $[+8.1, +17.7, -1.7, +1.0, +10.3, +20.6, +5.6, +6.6, +5.3, -9.0]$.

$$\overline{\text{err}}(M_1) = 27.72, \quad \overline{\text{err}}(M_2) = 21.27 \implies \bar{d} = \frac{64.5}{10} = \mathbf{6.45}$$ $$\text{var}(M_1 - M_2) = \frac{1}{k}\sum_{i=1}^{10}(d_i - \bar{d})^2 = \frac{681.225}{10} = 68.1225 \implies t = \frac{6.45}{\sqrt{68.1225/10}} = \mathbf{2.4712} \quad (\text{or } 2.3444 \text{ with } k-1)$$

• Critical value at $\alpha = 0.01$ ($\text{sig}/2 = 0.005$, $\text{df} = 9$): $t_{0.005,\,9} = \mathbf{3.250}$. Since $|t| = 2.4712 \lt 3.250$ ($p = 0.0355 \gt 0.01$), we fail to reject $H_0$: the difference is not statistically significant at the $1\%$ level (though it is significant at $5\%$, $t_{0.025,9}=2.262$).

Topic 10 Mandated Example: Outliers (PPTs) Local Outlier Factor (LOF)
Problem: Consider 4 data objects lying on a 1D real coordinate line: $A=0, B=1, C=2, P=6$. Using neighborhood size $k=2$, compute the $2$-distance, reachability distance, local reachability density ($\text{lrd}$), and the final $\text{LOF}_2(P)$. Explain why LOF correctly declares $P$ an outlier while $B$ and $C$ remain inliers.

Step-by-Step Derivation:

1. 2-Distances & Neighborhoods:
$d_2(A)=2, N_2(A)=\{B,C\}$. $d_2(B)=1, N_2(B)=\{A,C\}$. $d_2(C)=2, N_2(C)=\{B,A\}$. $d_2(P)=5, N_2(P)=\{C,B\}$.
2. Local Reachability Densities ($\text{lrd}_2$):
For $B$: $\text{reach-dist}_2(A,B) = \max\{1, 1\} = 1$, $\text{reach-dist}_2(C,B) = \max\{1, 1\} = 1 \implies \text{lrd}_2(B) = \frac{2}{1+1} = \mathbf{1.0}$.
For $C$: $\text{reach-dist}_2(B,C) = \max\{2, 1\} = 2$, $\text{reach-dist}_2(A,C) = \max\{2, 2\} = 2 \implies \text{lrd}_2(C) = \frac{2}{2+2} = \mathbf{0.5}$.
For $P$: $\text{reach-dist}_2(P,C) = \max\{2, 4\} = 4$, $\text{reach-dist}_2(P,B) = \max\{1, 5\} = 5 \implies \text{lrd}_2(P) = \frac{2}{4+5} = \frac{\mathbf{2}}{\mathbf{9}} \approx \mathbf{0.2222}$.
3. Final Local Outlier Factor $\text{LOF}_2(P)$:
$$\text{LOF}_2(P) = \frac{\frac{\text{lrd}_2(C)}{\text{lrd}_2(P)} + \frac{\text{lrd}_2(B)}{\text{lrd}_2(P)}}{2} = \frac{\frac{0.5}{2/9} + \frac{1.0}{2/9}}{2} = \frac{2.25 + 4.5}{2} = \mathbf{3.375}$$ Because $\text{LOF}_2(P) = 3.375 \gg 1.0$, $P$ has local density over $3\times$ sparser than its surrounding neighbors, unambiguously categorizing it as an outlier.

Ch 5 Paper (i) Han & Fu (TKDE 1999)

Mining Multiple-Level Association Rules in Large Databases

Core Problem: Mining at high abstraction levels yields trivial rules (e.g. `Dairy` $\to$ `Bread`), while mining at low abstraction levels yields low support (e.g. `Dairyland 2% Milk` has $<0.01\%$ support).

Key Innovations:

  • Taxonomy Concept Hierarchies with progressive minimum support thresholds (higher minsup at Level 1, reduced minsup at Level 2).
  • Redundancy Filtering: A rule at Level $l$ is redundant if its confidence is expected from its ancestor rule at Level $l-1$.

Ch 5 Paper (ii) Srikant & Agrawal (SIGMOD 1996)

Mining Quantitative Association Rules in Large Relational Tables

Core Problem: Boolean association rules cannot directly handle numeric attributes (e.g. `Age`, `Income`) without information loss or combinatorial explosion.

Key Innovations:

  • Equi-depth binning partition, followed by merging consecutive bins to discover generalized interval rules (e.g. $\text{Age:}[20..30] \Rightarrow \text{Cars}:1$).
  • Partial Completeness Bound $K$: Formal mathematical guarantee that no frequent itemset will be lost due to discretization error: $K = \frac{2-m}{2-2m}$.
  • Minimum interest measure $R$ to prune redundant sub-interval rules.

Ch 5 Paper (iii) Liu, Liao, Choudhary (PAKDD 2005)

A Two-Phase Algorithm for Fast Discovery of High Utility Itemsets

Core Problem: Frequency $\ne$ Profitability. Items with high profit margin may appear infrequently. However, utility does not satisfy the downward closure property!

Key Innovations:

  • Transaction-Weighted Utilization (TWU): $TWU(X) = \sum_{T \supseteq X} TU(T)$.
  • TWDC Property: If $TWU(X) < min\_util$, then $X$ and any superset $Y \supseteq X$ cannot be high utility. Downward closure is restored!
  • Two-Phase Architecture: Phase 1 discovers Candidate High Utility Itemsets (HTWUIs); Phase 2 performs one database scan to prune false positives.

Ch 8 Paper (i) Ng & Han (TKDE 1994)

CLARANS: Clustering Objects for Spatial Data Mining

Core Problem: Partitioning Around Medoids (PAM) has $O(k(n-k)^2)$ complexity, making it intractable for large datasets. CLARA fixed sampling biases against non-uniform clusters.

Key Innovations:

  • Treats clustering as graph search: Nodes are sets of $k$ medoids; edges connect sets differing by a single medoid swap.
  • Randomized local search: Examines up to `maxneighbor` random neighbors. If cost improves, jump to neighbor; otherwise record local minimum. Repeat `numlocal` times.

Ch 8 Paper (ii) Zhang, Ramakrishnan, Livny (SIGMOD 1996)

BIRCH: An Efficient Data Clustering Method for Very Large Databases

Core Problem: Existing clustering algorithms require multiple passes over the entire dataset and hold all points in RAM.

Key Innovations:

  • Clustering Feature (CF) Vector: $CF = (N, \vec{LS}, SS)$ compresses arbitrary cluster into 3 summary statistics.
  • CF-Additivity Theorem: $CF_1 + CF_2 = (N_1+N_2, \vec{LS}_1+\vec{LS}_2, SS_1+SS_2)$. Cluster diameter $D$ computed purely from $CF$.
  • CF-Tree: Height-balanced B+-tree like structure with branching factor $B$ and leaf threshold $T$. Single pass $O(n)$ data loading!

DBSCAN: Density-Based Algorithm with Noise

Core Problem: Partitioning algorithms (k-Means) can only find convex spherical clusters and are extremely sensitive to outliers.

Key Innovations:

CHAMELEON: Hierarchical Clustering Using Dynamic Modeling

Core Problem: CURE and ROCK use static global user parameters and ignore the internal interconnectivity and closeness of clusters.

Key Innovations:

  • Two-Phase Framework: (1) Graph partitioning on k-NN graph into dense sub-clusters using hMETIS; (2) Agglomerative hierarchical merge using dynamic modeling.

  • Relative Closeness (RC): Normalizes average cross-cluster edge weights by internal edge weights. Clusters merge only if both $RI$ and $RC$ are high.

Exam Reference

1. Preprocessing, Distances & Correlation

Minkowski Distance ($L_p$ norm): $$d(\vec{x}, \vec{y}) = \left(\sum_{i=1}^n |x_i - y_i|^p\right)^{1/p} \quad (p=1: \text{Manhattan}, p=2: \text{Euclidean})$$
Cosine Similarity: $$\text{sim}(\vec{x}, \vec{y}) = \frac{\vec{x} \cdot \vec{y}}{\|\vec{x}\| \|\vec{y}\|}$$
Chi-Square Independence Statistic: $$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}}, \quad E_{ij} = \frac{count(A=a_i) \times count(B=b_j)}{N}$$

2. Data Warehousing & Cubes

Lattice of Cuboids: $$\text{Total Cuboids} = 2^n \quad (n = \text{number of dimensions})$$
Total Data Cube Cells: $$\text{Total Cells} = \prod_{i=1}^n (|D_i| + 1)$$
Greedy Lattice Selection (Harinarayan et al. '96): $$\text{Benefit}(v, S) = \sum_{w \le v} \max(0, C(w, S) - C(w, S \cup \{v\}))$$ $$\text{Guaranteed Approximation Ratio} \ge 1 - \frac{1}{e} \approx 63\%$$

3. Classification & Decision Trees

Entropy & Information Gain: $$Info(D) = -\sum_{i=1}^m p_i \log_2(p_i), \quad Info_A(D) = \sum_{j=1}^v \frac{|D_j|}{|D|} Info(D_j)$$ $$Gain(A) = Info(D) - Info_A(D)$$
Gain Ratio (C4.5): $$SplitInfo_A(D) = -\sum_{j=1}^v \frac{|D_j|}{|D|} \log_2 \frac{|D_j|}{|D|}, \quad GainRatio(A) = \frac{Gain(A)}{SplitInfo_A(D)}$$
Gini Impurity (CART): $$Gini(D) = 1 - \sum_{i=1}^m p_i^2, \quad Gini_A(D) = \frac{|D_1|}{|D|}Gini(D_1) + \frac{|D_2|}{|D|}Gini(D_2)$$

4. SVM & Cluster Quality Metrics

SVM Margin Width: $$\text{Hyperplane: } \vec{w} \cdot \vec{x} + b = 0 \implies \text{Margin Width } \gamma = \frac{2}{\|\vec{w}\|}$$
Silhouette Coefficient $s(i)$: $$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}, \quad -1 \le s(i) \le +1$$ ($a(i)$: average intra-cluster distance, $b(i)$: min average nearest-cluster distance).
BIRCH Cluster Diameter: $$D = \sqrt{\frac{2 N \cdot SS - 2 \|\vec{LS}\|^2}{N(N-1)}}$$

Special Focus

Q1: How can Clustering (Ch 8) be used as a Preprocessing step for Classification (Ch 6 & 7)?

1. Unsupervised Discretization: Clustering high-dimensional continuous attributes into $k$ discrete clusters replaces raw continuous values with cluster IDs, preventing overfitting in Decision Trees and Naive Bayes.

2. Semi-Supervised Label Propagation: In large datasets where only 5% of samples are labeled, run DBSCAN or K-Means. Propagate known labels to unlabelled samples within dense pure clusters, then train an SVM classifier.

3. Prototype Selection for k-NN: To reduce $O(n)$ inference latency in k-Nearest Neighbor lazy learning, cluster the training instances with BIRCH/K-Means and use cluster centroids as prototypes.

Q2: How does OLAP / Cube Computation (Ch 3) intersect with Pattern Mining (Ch 4 & 5)?

1. Multi-Dimensional Association Rule Mining: Instead of single-dimensional market basket transactions, rules can involve multiple relational attributes from star schemas (e.g. $\text{age}(X, \text{"20..29"}) \wedge \text{buys}(X, \text{"laptop"}) \Rightarrow \text{buys}(X, \text{"backpack"})$).

2. Iceberg Cube Pruning via BUC: BUC's bottom-up anti-monotonicity pruning is conceptually identical to the Apriori property. Both prune search subtrees when aggregated counts fail to satisfy a minimum threshold.

Q3: Deep Learning (Sec 10.1) vs. Support Vector Machines (Sec 7.3)

1. Convexity vs Non-Convex Optimization: SVM optimization is a quadratic programming problem with a globally optimal convex solution. Neural network backpropagation solves non-convex gradient descent, subject to local minima and saddle points.

2. Kernel Trick vs Representation Learning: SVMs project data into high dimensions via fixed implicit kernels (RBF, Polynomial). Deep Learning networks learn hierarchical non-linear feature representations automatically through successive hidden layers.
