1. The Core AI Bottleneck

Why Classic AI Failed on Databases (And How AOI Saved It)

In the 1980s, classic AI machine learning algorithms (like Mitchell's Version Spaces) examined training data tuple-by-tuple. For a database of 100,000 student records, examining each tuple one-by-one against concept hypotheses took days and crashed memory.

🥨 The Beginner's Analogy: If someone asks you to summarize a library of 100,000 books, you don't read each book sentence-by-sentence to build an abstract grammar. You look at the bookshelf labels: "These 30,000 are 20th Century European History; these 20,000 are Quantum Physics." Attribute-Oriented Induction does exactly this by climbing background concept trees directly on relational table columns.

3. Core Algorithms Demystified

LCHR (Characteristic) vs. LCLR (Classification) Rules

Algorithm LCHR: Learning Characteristic Rules

Goal: Summarize the general profile of a target group (e.g., successful grant applicants).

The 5 Generalization Strategies:

  1. Attribute Removal: If attribute has many distinct values and NO concept hierarchy exists (e.g., Student ID or Name), DROP IT.
  2. Least Commitment Principle: Generalize the lowest-level concepts first to retain maximal information.
  3. Concept Tree Ascendance: Replace child values with parent category in hierarchy.
  4. Threshold Control: If distinct values in a column $\le T$ (threshold, e.g. 3), stop generalizing that column.
  5. Tuple Merging: Aggregate duplicate generalized tuples and sum their counts ($t$-weight).

Algorithm LCLR: Learning Classification Rules

Goal: Contrast a target class $P$ against a contrasting class $N$ (e.g., accepted students vs. rejected students).

Overlapping Tuple Elimination:

When both classes are generalized up the concept tree, tuples that appear in BOTH classes ($P \cap N$) provide NO discriminative power. LCLR marks and ELIMINATES overlapping tuples!

The remaining tuples form a pure, minimal discriminant classification rule separating the two groups.

4. Midsem Practice Quiz

Exam Retention Check

Q1. During Attribute-Oriented Induction, what should the algorithm do with an attribute like Social_Security_Number that has 10,000 distinct values and NO concept tree?

Correct! Strategy 1 (Attribute Removal) dictates that if an attribute contains many distinct values with no concept hierarchy, it cannot be generalized usefully and must be dropped.
