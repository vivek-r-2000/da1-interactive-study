Section 1: Fundamentals • Card 1 of 32

What is Cluster Analysis? (Slide #3-10)

Cluster analysis (or clustering) is the process of partitioning a set of data objects into subsets called clusters. Unlike classification, clustering is fundamentally unsupervised: there are no predefined class labels or training teacher.

🎯 Core Objective: Objects within the same cluster must have high intra-class similarity (cohesion), while objects in different clusters must have low inter-class similarity (distinctness).

Clustering as Both Insight and Utility:

🔍 Understanding & Insight:

• Biology: taxonomies of living organisms, functional gene groups.

• Information Retrieval: grouping search queries and documents.

• Marketing: finding distinct customer behavior segments.

⚡ Data Utility & Summarization:

• Data Reduction: represent millions of raw points by cluster prototypes.

• Image Compression: vector quantization of color palettes.

• Outlier Detection: objects not fitting any cluster signal anomalies.

Quality & Requirements in Data Mining (Slide #11, 29)

Clustering algorithms in large-scale data mining must satisfy rigorous practical requirements beyond toy benchmark datasets:

1. Scalability: Datasets contain millions of tuples. Algorithms must run in linear $O(n)$ or near-linear $O(n \log n)$ time and perform minimal disk scans.
2. Diverse Attribute Types: Real data blends numeric (interval/ratio), binary, nominal, ordinal, and spatial/text attributes.
3. Discovery of Arbitrary Shapes: Spherical clusters (assumed by K-Means) fail on concentric rings, serpentine shapes, or elongated density flows.
4. Robustness to Noise & Outliers: Missing data, sensor spikes, and background noise must not distort cluster centroids.
5. Insensitivity to Input Order: The final clustering structure should not change if the database rows are permuted.
6. High Dimensionality: Handle the "curse of dimensionality" where distance metrics lose contrast as dimension $p \to \infty$.

Minkowski Distance & Data Standardization (Slide #19-23)

For two $p$-dimensional numerical objects $i = (x_{i1}, \dots, x_{ip})$ and $j = (x_{j1}, \dots, x_{jp})$, the general Minkowski Distance ($L_h$ norm) is:

$$d(i, j) = \left( \sum_{f=1}^p |x_{if} - x_{jf}|^h \right)^{1/h}$$
$h = 1$: Manhattan ($L_1$)

City-block distance: sum of absolute differences. Equivalent to Hamming distance on binary data.

$h = 2$: Euclidean ($L_2$)

Straight-line Euclidean distance: rotationally invariant, sensitive to large outliers.

$h \to \infty$: Supremum ($L_\infty$)

Chebyshev distance: $d(i, j) = \max_{f=1}^p |x_{if} - x_{jf}|$. Driven by maximal single dimension.

The Necessity of Normalization (Slide #19):

If salary is measured in \$100,000s and age in years (18-80), unscaled Euclidean distance is 99.9% dominated by salary! Z-score normalization rescales features to zero mean and unit variance:

$$z_{if} = \frac{x_{if} - \mu_f}{\sigma_f} \quad \text{or using Mean Absolute Deviation: } s_f = \frac{1}{n} \sum_{i=1}^n |x_{if} - \mu_f|$$

Non-Numeric, Binary & Mixed Attributes (Slide #16-28)

Real databases rarely contain purely continuous values. Han & Kamber define exact proximity formulas for heterogeneous types:

1. Binary Attributes (Contingency Table):

Let $q$ be count where both $i, j = 1$; $t$ where both $= 0$; $r$ where $i=1, j=0$; $s$ where $i=0, j=1$.

Symmetric Binary (e.g. Gender):

$$d(i, j) = \frac{r + s}{q + r + s + t}$$

Asymmetric Binary (Jaccard Distance):

$$d(i, j) = \frac{r + s}{q + r + s}$$ (ignores $t$ mutual absence)

2. Nominal & Ordinal Attributes:

• Nominal (States $>2$): Simple matching dissimilarity $d(i, j) = \frac{p - m}{p}$, where $m$ is number of matches.

• Ordinal (Ranks \$1, \dots, M_f$): Map rank to normalized range $[0, 1]$ via $z_{if} = \frac{r_{if} - 1}{M_f - 1}$, then apply Minkowski distance.

3. Mixed Types: Gower's General Dissimilarity Coefficient (Slide #26):

Blends all attribute types into a single distance: $$d(i, j) = \frac{\sum_{f=1}^p \delta_{ij}^{(f)} d_{ij}^{(f)}}{\sum_{f=1}^p \delta_{ij}^{(f)}}$$ where $\delta_{ij}^{(f)} = 0$ if values are missing or asymmetric binary mutual zeros (\$0-0$), and \$1$ otherwise.

4. Cosine Similarity for Sparse Text Vectors (Slide #27):

$$\cos(\vec{d}_1, \vec{d}_2) = \frac{\vec{d}_1 \cdot \vec{d}_2}{\|\vec{d}_1\| \|\vec{d}_2\|}$$ Computes angular alignment, completely invariant to document length!

K-Means: Centroid Partitioning (Slide #38-48)

Given dataset $D$ of $n$ objects and integer $k$, K-Means partitions data into $k$ disjoint clusters $C_1, \dots, C_k$ such that the Sum of Squared Errors (SSE) is minimized:

$$SSE = \sum_{i=1}^k \sum_{p \in C_i} \|p - \vec{c}_i\|^2 \quad \text{where } \vec{c}_i = \frac{1}{|C_i|} \sum_{p \in C_i} p$$

Lloyd's Algorithm (Iterative Relocation):

  1. Initialize: Arbitrarily select $k$ objects as initial cluster centers (centroids).
  2. Assignment: Assign each object $p$ to the nearest centroid based on Euclidean distance.
  3. Update: Recompute the centroid of each cluster as the mean of all points assigned to it.
  4. Convergence: Repeat steps 2-3 until centroids do not move or SSE stabilizes.
✅ Strengths:

• Efficient: $O(t \cdot k \cdot n \cdot d)$ where $t$ is iterations, $k \ll n$.

• Guaranteed to converge to a local minimum.

⚠️ Critical Weaknesses:

• Highly sensitive to outliers (squaring error heavily pulls centroids).

• Only finds spherical, convex clusters of similar size.

• Highly dependent on initial random seeds.

Section 2: Partitioning • Card 8 of 32

K-Means++ & Bisecting K-Means (Slide #48-52)

1. K-Means++ (Arthur & Vassilvitskii 2007)

Standard K-Means picks initial seeds uniformly at random, often causing clusters to get stuck in poor local minima. K-Means++ seeds centroids sequentially with probability proportional to their squared distance to the nearest existing centroid:

$$P(x) = \frac{D(x)^2}{\sum_{x' \in D} D(x')^2}$$

Mathematical Guarantee: K-Means++ provides an expected approximation ratio $O(\log k)$ competitive with the optimal clustering!

2. Bisecting K-Means

A divisive hierarchical approach that repeatedly splits clusters: starts with 1 cluster containing all data, chooses the cluster with largest SSE, and bisects it using 2-Means until $k$ clusters are reached. Less susceptible to initialization traps than standard K-Means!

K-Medoids & The PAM Algorithm (Slide #53-62)

Instead of taking the mean value of points in a cluster (which may be an artificial point sensitive to outliers), K-Medoids selects actual representative data objects (medoids) located centrally within the cluster.

$$\text{Absolute Error Criterion: } E = \sum_{i=1}^k \sum_{p \in C_i} \|p - o_i\|$$

PAM (Partitioning Around Medoids - Kaufman & Rousseeuw 1990):

PAM checks whether replacing an existing medoid $o_i$ with a non-medoid candidate $o_{\text{random}}$ reduces total cost. Total swap cost: $$TC_{ih} = \sum_{j} C_{jih}$$

Case 1: $p$ currently belongs to $o_i$. If $o_i$ is replaced by $o_h$, and $p$ is closest to another medoid $o_2$: $p$ reassigns to $o_2$.
Case 2: $p$ currently belongs to $o_i$. If $p$ is closest to new candidate $o_h$: $p$ reassigns to $o_h$.
Case 3: $p$ belongs to $o_2 \neq o_i$. If $p$ remains closest to $o_2$: no change ($C_{jih} = 0$).
Case 4: $p$ belongs to $o_2 \neq o_i$. If $p$ is closer to new candidate $o_h$: $p$ reassigns to $o_h$.

PAM Complexity: $O(k(n-k)^2)$ per iteration — extremely robust against outliers, but prohibitively slow for large $n$!

Scaling K-Medoids: CLARA & CLARANS (Slide #63-71)

1. CLARA (Clustering LARge Applications - Kaufman & Rousseeuw 1990)

Draws multiple random samples (typically 5 samples of size \$40 + 2k$), applies PAM on each sample to find the best $k$ medoids, and assigns the entire dataset to the best sample medoids.

Limitation: If the true medoids are missed in the sample, CLARA can never find them!

2. CLARANS (Clustering Large Applications based on RANdomized Search - Ng & Han 2002)

Models the search space as a graph: each node is a collection of $k$ medoids. Two nodes are neighbors if they differ by exactly 1 medoid.

• Instead of examining all $k(n-k)$ neighbors (like PAM), CLARANS samples a maximum of maxneighbor randomized neighbors.

• If a neighbor improves cost, move there immediately; otherwise, declare local minimum after maxneighbor failed attempts.

• Repeats search numlocal times to find the best global local minimum.

CLARANS is asymptotically faster than PAM and consistently discovers higher-quality clusters than CLARA!

Categorical Partitioning: K-Modes & K-Prototypes (Slide #72-74)

How do we cluster categorical or transactional data where means and Euclidean distances are meaningless? (Zhexue Huang, 1998)

1. K-Modes for Categorical Data:

• Replaces cluster means with cluster modes (the most frequent category per attribute).

• Replaces Euclidean distance with simple matching dissimilarity: $d(x, y) = \sum_{j=1}^p \delta(x_j, y_j)$ where $\delta(a,b) = 0$ if equal, \$1$ if different.

• Updates modes on the fly using category frequencies.

2. K-Prototypes for Mixed Data:

Integrates numeric and categorical variables by weighting the categorical dissimilarity with parameter $\gamma$:

$$d(x, y) = \sum_{j=1}^{p_r} (x_j - y_j)^2 + \gamma \sum_{j=p_r+1}^p \delta(x_j, y_j)$$

When $\gamma = 0$, reduces to K-Means; when $\gamma \to \infty$, categorical matching dominates.

Hierarchical Clustering: Agglomerative vs Divisive (Slide #75-81)

Hierarchical clustering groups objects into a tree or nested hierarchy of clusters called a dendrogram. Does not require specifying $k$ in advance: users cut the dendrogram at any desired similarity threshold.

AGNES (Agglomerative - Bottom-Up):

• Starts with $n$ individual single-point clusters.

• At each step, merges the two clusters with the minimum inter-cluster distance.

• Terminates when all points merge into a single root cluster.

DIANA (Divisive - Top-Down):

• Starts with all $n$ points in one master cluster.

• At each step, splits the cluster with the highest diameter into two subclusters.

• Terminates when every object forms its own leaf cluster.

⚠️ The Rigid Merge Trap: Once two clusters are merged in AGNES (or split in DIANA), the decision can never be undone! Mistakes made in early iterations propagate through all subsequent levels.

Inter-Cluster Linkage Criteria (Slide #82-90)

How do we measure the distance between two clusters $A$ and $B$ containing multiple points?

1. Single Link (Minimum Distance / MIN):

$$d(A, B) = \min_{p \in A, q \in B} d(p, q)$$

Can handle non-elliptical, elongated shapes. Fatal weakness: Susceptible to chaining effect where a single noisy bridge of points connects two distinct clusters.

2. Complete Link (Maximum Distance / MAX):

$$d(A, B) = \max_{p \in A, q \in B} d(p, q)$$

Avoids chaining; produces compact, spherical clusters. Weakness: Sensitive to outliers and tends to break large natural clusters.

3. Average Link (Mean Distance):

$$d(A, B) = \frac{1}{|A||B|} \sum_{p \in A} \sum_{q \in B} d(p, q)$$

A robust compromise between single and complete link; less sensitive to noise.

4. Ward's Minimum Variance Method:

$$\Delta ESS(A, B) = \frac{|A||B|}{|A| + |B|} \|\vec{c}_A - \vec{c}_B\|^2$$

Merges clusters that cause the smallest increase in total within-cluster sum of squares. Highly popular in practice.

Section 3: Advanced Hierarchical • Card 15 of 32

BIRCH: CF-Vectors & CF-Tree (Zhang et al. 1996 - Slide #91-99)

BIRCH (Balanced Iterative Reducing and Clustering using Hierarchies) achieves $O(n)$ scalability by summarizing large datasets in a height-balanced in-memory CF-Tree with a single data scan.

The Clustering Feature (CF) Vector: A cluster of $N$ $d$-dimensional points is compressed into a 3-tuple: $$CF = (N, \vec{LS}, SS)$$ where $N$ is count, $\vec{LS} = \sum_{i=1}^N p_i$ (linear sum), and $SS = \sum_{i=1}^N p_i^2$ (square sum).

CF Additivity Theorem (The Core Power):

If clusters $C_1$ and $C_2$ are merged, the new CF is simply the component-wise sum:

$$CF_1 + CF_2 = (N_1 + N_2, \vec{LS}_1 + \vec{LS}_2, SS_1 + SS_2)$$
Centroid $x_0 = \frac{\vec{LS}}{N}$
Radius $R = \sqrt{\frac{SS}{N} - (\frac{\vec{LS}}{N})^2}$
Diameter $D = \sqrt{\frac{2N \cdot SS - 2\vec{LS}^2}{N(N-1)}}$

Phase 1: Scans data to build a CF-tree within memory limit using branching factor $B$ and diameter threshold $T$.
Phase 2: Applies global hierarchical or partitioning clustering directly on the compact leaf subclusters!

CURE: Representative Points & Shrinking (Guha et al. 1998 - Slide #100-104)

CURE (Clustering Using REpresentatives) resolves the conflict between centroid methods (which only find spherical clusters) and all-points methods (which are slow and sensitive to chaining).

How CURE Works:

• Represents each cluster by a fixed number $c$ of well-scattered representative points (captures non-spherical shapes).

• Shrinking Step: Shrinks representative points toward the cluster centroid by a factor $\alpha \in [0, 1]$:

$$p_{\text{shrunk}} = p + \alpha (\vec{c} - p)$$

• Shrinking dampens the effects of extreme outliers and prevents single-link chaining.

• Distance between two clusters is the minimum distance between their shrunk representative points.

Scalability via Sampling & Partitioning: CURE draws a random sample, partitions it into $p$ blocks, clusters each block in memory, then performs second-pass global clustering and assigns disk tuples to the nearest representative point.
Section 3: Graph & Transactional • Card 17 of 32

CHAMELEON & ROCK (Slide #105-108)

1. CHAMELEON: Graph Partitioning & Dynamic Modeling (Karypis et al. 1999)

Builds a k-nearest neighbor (k-NN) graph of objects, then partitions it into many tiny subclusters using multi-level graph bisection (hMETIS). Subclusters are merged only if they have high:

Relative Interconnectivity (RI):

$$RI(C_i, C_j) = \frac{2 |EC_{C_i, C_j}|}{|EC_{C_i}| + |EC_{C_j}|}$$

Normalizes edge cuts connecting $C_i$ and $C_j$ by internal cuts.

Relative Closeness (RC):

$$RC(C_i, C_j) = \frac{\bar{S}_{EC_{C_i, C_j}}}{\frac{|C_i|}{|C_i|+|C_j|}\bar{S}_{EC_{C_i}} + \dots}$$

Compares connection density against internal cluster density.

2. ROCK: Robust Clustering using Links (Guha et al. 2000)

Designed for categorical and market-basket transaction data. Standard Jaccard distance fails when transactions share few items. ROCK defines links: the number of common shared neighbors between two points:

$$link(p_i, p_j) = \sum_x \text{sim}(p_i, x) \cdot \text{sim}(p_j, x)$$

Pairs with high shared neighbors are clustered, even if their direct similarity is weak!

Density-Based Fundamentals: Core, Border & Noise (Slide #109-112)

Density-based clustering discovers clusters of arbitrary non-spherical shapes (rings, snakes, dense blobs) and isolates noise. Given two parameters: radius $\epsilon$ (Eps) and minimum points $MinPts$:

🟢 Core Point:

Its $\epsilon$-neighborhood contains at least $MinPts$ points: $$|N_\epsilon(p)| \ge MinPts$$

🟡 Border Point:

Not a core point, but lies within the $\epsilon$-neighborhood of a core point ($|N_\epsilon(p)| < MinPts$).

🔴 Noise Point:

Neither a core point nor a border point. Categorized as an outlier.

Density Connectivity Definitions:

• Directly Density-Reachable: $p$ is directly reachable from $q$ if $q$ is a core point and $p \in N_\epsilon(q)$ (asymmetric).

• Density-Reachable: $p$ is reachable from $q$ via a chain of core points $p_1, \dots, p_n$ where $p_1 = q, p_n = p$ (transitive, asymmetric).

• Density-Connected: $p$ and $q$ are density-connected if there exists an intermediate point $o$ such that both $p$ and $q$ are density-reachable from $o$ (symmetric!).

DBSCAN Algorithm & Mechanics (Ester et al. 1996 - Slide #110-112)

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) defines a cluster as a maximal set of density-connected points.

Algorithm Step-by-Step:

  1. Mark all points as unvisited.
  2. Arbitrarily pick an unvisited point $p$ and mark it as visited.
  3. Retrieve its $\epsilon$-neighborhood $N_\epsilon(p)$.
  4. If $|N_\epsilon(p)| < MinPts$, tentatively label $p$ as NOISE (may later become a border point).
  5. If $|N_\epsilon(p)| \ge MinPts$, create a new cluster $C$ containing $p$. Expand cluster by visiting all unvisited points in $N_\epsilon(p)$; if they are core points, expand their neighborhoods recursively.
  6. Repeat until all points are processed.
✅ Advantages:

• Discovers arbitrary shapes (crescents, rings).

• No need to specify cluster count $k$.

• Highly robust against background noise.

⚠️ Bottlenecks:

• Fails when clusters have drastically varying densities.

• Highly sensitive to $\epsilon$ and $MinPts$.

• $O(n^2)$ worst-case; $O(n \log n)$ with spatial index (R*-tree).

OPTICS: Overcoming Varying Densities (Ankerst et al. 1999 - Slide #113-118)

DBSCAN cannot cluster datasets containing both sparse and dense clusters simultaneously because a single global $\epsilon$ either merges dense clusters or splits sparse ones. OPTICS (Ordering Points To Identify the Clustering Structure) solves this without requiring a rigid global density cutoff.

1. Core Distance of $p$:

The smallest radius $\epsilon'$ such that $p$ is a core point w.r.t. $MinPts$. Undefined if $|N_\epsilon(p)| < MinPts$.

2. Reachability Distance of $p$ from $o$:

$$\text{reach-dist}_\epsilon(p, o) = \max(\text{core-dist}_\epsilon(o), d(o, p))$$

Undefined if $o$ is not a core point.

📈 The Reachability Plot: OPTICS outputs a linear cluster ordering of data points alongside their reachability distances. When plotted, valleys and troughs represent clusters! Deep valleys correspond to dense clusters; shallow wide valleys correspond to sparse clusters.

DENCLUE: Kernel Density Functions (Hinneburg & Keim 1998 - Slide #119-122)

DENCLUE (DENsity-based CLUstEring) provides a rigorous mathematical foundation using non-parametric kernel density estimation (Parzen window):

$$f_K(x) = \frac{1}{n h^d} \sum_{i=1}^n K\left( \frac{x - x_i}{h} \right) \quad \text{e.g. Gaussian Kernel: } K(z) = \frac{1}{(2\pi)^{d/2}} e^{-\frac{\|z\|^2}{2}}$$
Density Attractor: Local maxima of the density function found via gradient hill-climbing: $\nabla f(x)$.
Center-Defined Clusters: All points that climb to the same density attractor with density $\ge \xi$ form a cluster.
Arbitrary-Shape Clusters: Connected paths of density attractors whose bridge densities exceed threshold $\xi$ merge into complex shapes.

Section 5: Grid-Based • Card 24 of 32

STING: Statistical Information Grid (Wang et al. 1997 - Slide #124-127)

STING divides the spatial area into rectangular cells in a multi-resolution hierarchical pyramid. Each cell at a higher level is partitioned into a number of smaller cells (typically 4) at the next lower level.

Precomputed Cell Statistics:

• Attribute-independent: point count $n$.

• Attribute-dependent: mean $m$, standard deviation $s$, min, max.

• Distribution type: Normal, Uniform, Exponential, or NONE.

Top-Down Query Processing:

  1. Start at root layer; calculate probability that each cell satisfies query condition.
  2. Prune irrelevant cells immediately; traverse children of relevant cells only.
  3. Repeat downward to the leaf level; assemble contiguous dense cells into final clusters.
⚡ Time Complexity: Query time is $O(K)$ where $K$ is the number of grid cells at the bottom layer — completely independent of data count $N$!
Section 5: Grid & Subspace • Card 25 of 32

CLIQUE: High-Dimensional Subspace Clustering (Agrawal et al. 1998 - Slide #128-131)

In high dimensions ($d > 50$), data becomes sparse and almost all points are equidistant (curse of dimensionality). Real clusters exist only in subspaces of lower dimensionality. CLIQUE (Clustering In QUEst) automatically identifies dense units in subspaces.

The Apriori Property of Dense Subspaces: If a $k$-dimensional grid cell is dense (density $> \tau$), then each of its $(k-1)$-dimensional projections must also be dense!

The 3 Major Steps of CLIQUE:

1. Subspace Identification: Partitions each dimension into intervals and finds 1-D dense units. Uses the Apriori property to join $(k-1)$-D dense units into $k$-D candidate units.
2. Cluster Assembly: Merges adjacent dense units in the identified subspace to form maximal connected clusters.
3. Rule Generation: Translates dense units into minimal Disjunctive Normal Form (DNF) boolean rules for human interpretability.
Section 6: Cluster Validation • Card 26 of 32

Clustering Tendency & Hopkins Statistic (Slide #133-134)

Before running any clustering algorithm, you must assess clustering tendency: does the dataset possess non-random structure, or is it merely uniform noise? (Algorithms will force clusters even on pure noise!)

$$H = \frac{\sum_{i=1}^p y_i}{\sum_{i=1}^p x_i + \sum_{i=1}^p y_i}$$

• Sample $p$ points $q_1, \dots, q_p$ uniformly at random from the entire data space (artificial points). Let $y_i$ be distance from $q_i$ to its nearest neighbor in dataset $D$.

• Sample $p$ real points $x_1, \dots, x_p$ from dataset $D$. Let $x_i$ be distance from $x_i$ to its nearest neighbor in $D$.

If $H \approx 0.5$:

Data is uniformly distributed. Zero clustering tendency! Clustering will produce misleading artifacts.

If $H \to 1.0$:

Real points are tightly clustered while artificial points lie far from data. Strong cluster structure exists!

Section 6: Cluster Validation • Card 27 of 32

Determining the Number of Clusters k (Slide #135-136)

Specifying $k$ is often an arbitrary guess. Han & Kamber detail 3 empirical and quantitative strategies to choose $k$:

1. Empirical Rule of Thumb:
$$k \approx \sqrt{n / 2}$$

Quick estimate for dataset of $n$ points (e.g. for $n=200$, $k \approx 10$).

2. The Elbow Method (Knee Point):

Run K-Means for $k = 2, 3, \dots, 10$ and plot $SSE$ versus $k$. SSE drops sharply while splitting true clusters, but levels off once splitting homogeneous clusters. The turning point ("elbow") is the optimal $k$.

3. Cross-Validation Stability:

Split dataset into $m$ subsets. Cluster $m-1$ subsets and project the held-out fold into the clusters. If cluster assignments remain stable across random splits (measured via Adjusted Rand Index), $k$ is genuine.

Section 6: Cluster Validation • Card 28 of 32

Extrinsic Quality: BCubed, NMI & ARI (Slide #137-140)

When ground-truth labels $C_g$ are available for benchmark validation, extrinsic methods compare the discovered clustering $C$ against $C_g$:

1. BCubed Precision & Recall Metrics (Slide #139):

Evaluates precision and recall for every individual data point $o$:

$$Precision(o) = \frac{|C(o) \cap C_g(o)|}{|C(o)|}$$
$$Recall(o) = \frac{|C(o) \cap C_g(o)|}{|C_g(o)|}$$

Averages over all objects; satisfies cluster homogeneity and completeness!

2. Rand Index (RI) & Adjusted Rand Index (ARI):

$$RI = \frac{TP + TN}{TP + FP + FN + TN}$$

• $TP$: pair in same cluster in both $C$ and $C_g$.

• ARI corrects for chance: $ARI = \frac{RI - E[RI]}{\max(RI) - E[RI]} \in [-1, 1]$. Value near \$0$ indicates random chance; \$1.0$ indicates perfect agreement.

Intrinsic Quality: The Silhouette Coefficient (Slide #141)

In real unsupervised mining, ground truth is absent. Intrinsic measures evaluate clustering quality using internal separation and cohesion. The Silhouette Coefficient is the industry standard:

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \quad \in [-1, +1]$$
$a(i)$: Within-Cluster Cohesion

Average distance from object $i$ to all other points in its own cluster.

$b(i)$: Nearest-Cluster Separation

Minimum average distance from object $i$ to points in any neighboring cluster.

• $s(i) \approx +1$: $a(i) \ll b(i)$. Object is tightly matched to its own cluster and far from neighbors. Excellent!
• $s(i) \approx 0$: $a(i) \approx b(i)$. Object lies right on the boundary between two clusters.
• $s(i) < 0$: Object is closer to neighboring cluster than its own. Misassigned point!
