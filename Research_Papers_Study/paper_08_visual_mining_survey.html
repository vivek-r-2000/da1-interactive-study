2. Taxonomy & Theoretical Paradigms

The 4 Core Visual Mining Paradigms

1. Geometric Techniques

Projecting multidimensional coordinates into 2D/3D spaces. Examples: Parallel Coordinates (where N dimensions are represented as N parallel vertical lines, and each tuple is a polygonal line traversing the axes).

2. Iconographic Techniques

Mapping multidimensional attributes to visual glyph features. Example: Chernoff Faces (mapping variables to eye size, eyebrow slant, mouth curvature) and Star Glyphs.

3. Pixel-Oriented Techniques

Mapping each attribute value to a single colored pixel, packed densely on screen via space-filling Hilbert or spiral curves (Daniel Keim's VisDB). Allows visualizing 1,000,000 data items on a single monitor!

4. Hierarchical Techniques

Dividing n-dimensional space into nested subspaces. Examples: Treemaps, Dimensional Stacking, and Cone Trees.

4. Active Retention Quiz

Test Your Understanding

1. What is Ben Shneiderman's Information Seeking Mantra?

Explanation: Correct! The mantra defines the gold standard for exploratory visualization interface design.

2. In Parallel Coordinates, how is a single multidimensional data tuple represented?

Explanation: Correct! Parallel coordinates map N orthogonal Cartesian dimensions into N parallel vertical lines.

3. What is the fundamental concept behind Pixel-Oriented visualization techniques?

Explanation: Correct! Pixel-oriented methods pack millions of data items onto a single display.

4. What is a key weakness of Chernoff Faces for high-dimensional exploration?

Explanation: Correct! Cognitive biases in facial perception create severe attribute weighting imbalances.

5. What distinguishes Visual Data MINING from simple Visual Exploration?

Explanation: Correct! The fusion of algorithmic extraction and visual human steering defines visual data mining.
