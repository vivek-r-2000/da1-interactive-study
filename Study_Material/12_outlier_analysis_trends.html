STING: Statistical Information Grid (Wang et al. 1997)

STING is a hierarchical grid-based technique that quantizes the spatial area into rectangular cells stored in a multi-resolution quad-tree structure.

Precomputed Cell Statistical Parameters:

For each cell at each hierarchical level, STING precomputes and stores:

  • • $n$: Attribute count
  • • $m$: Attribute mean
  • • $s$: Standard deviation
  • • $\min, \max$: Extreme bounds
  • • $\text{dist}$: Distribution type (Normal, Uniform, Exponential, None)

Bottom-up aggregation: Higher-level cell parameters are calculated directly from their 4 child cells without scanning raw data points!

Query Processing & Complexity

  1. Start at the top layer of the hierarchical tree.
  2. For each cell in the current layer, calculate the probability that it satisfies the user query using stored statistical parameters.
  3. Prune irrelevant cells; descend to child cells of relevant candidates.
  4. Repeat until the bottom layer is reached, then group contiguous relevant cells into clusters.
Time Complexity Advantage: Query time complexity is $O(K)$, where $K$ is the number of grid cells at the bottom layer ($K \ll N$). STING query execution is completely independent of the number of raw data tuples $N$!

CLIQUE: Subspace Clustering (Agrawal et al. 1998)

In high dimensions ($d > 20$), distance metrics break down because virtually all pairs of points become equidistant (the Curse of Dimensionality). Real clusters exist only in subspaces involving subsets of attributes.

The CLIQUE Apriori Subspace Principle:
A $k$-dimensional cell $C$ is dense ONLY IF all its $(k-1)$-dimensional projection cells are also dense.

This is identical to the Apriori property in Association Rule Mining: any subset of a frequent itemset must be frequent!

CLIQUE 3-Step Execution

  1. Identification of Subspaces: Partition each 1D attribute into equal intervals. Identify dense 1D units (count $\ge \xi$). Join dense 1D units to generate candidate 2D units, prune using the Apriori property, and iterate up to $k$ dimensions.
  2. Cluster Discovery: Connect contiguous adjacent dense cells in each dense subspace using depth-first search.
  3. Minimal Cluster Description: Generate minimal DNF Boolean expressions covering the rectangular dense regions.

DENCLUE: Kernel Density Attractors (Hinneburg & Keim 1998)

DENCLUE (DENsity-based CLUstEring) uses a rigorous statistical foundation based on non-parametric Kernel Density Estimation (KDE).

Influence Function & Overall Density:

Each data point $\mathbf{y}$ exerts an influence on any spatial point $\mathbf{x}$ via a Gaussian influence kernel:

$$f_{\text{Gaussian}}(\mathbf{x}, \mathbf{y}) = e^{-\frac{\|\mathbf{x} - \mathbf{y}\|^2}{2\sigma^2}}$$

The overall density $f_D(\mathbf{x})$ at point $\mathbf{x}$ is the sum of influence functions across all $N$ data points:

$$f_D(\mathbf{x}) = \frac{1}{N} \sum_{i=1}^N f_{\text{Gaussian}}(\mathbf{x}, \mathbf{x}_i)$$

Density Attractors & Hill Climbing

  • Density Attractor: A local maximum (peak) of the overall density function $f_D(\mathbf{x})$.
  • Points climb the gradient $\nabla f_D(\mathbf{x})$ toward their local density attractor using hill climbing.
  • Center-Defined Cluster: All points that climb to the same density attractor whose density $\ge \xi$.
  • Arbitrary-Shaped Cluster: Formed by merging multiple density attractors connected by a path of density $\ge \xi$.

Constraint-Based Clustering: User Guidance & COP-KMeans

Purely unsupervised clustering can produce technically valid clusters that are useless for domain applications. Semi-supervised clustering allows domain experts to inject pairwise constraints.

1. Must-Link Constraints (ML)

$$\text{ML}(d_i, d_j) \implies c(d_i) = c(d_j)$$

Specifies that instances $d_i$ and $d_j$ must be assigned to the exact same cluster. Transitive: $\text{ML}(a,b) \land \text{ML}(b,c) \implies \text{ML}(a,c)$.

2. Cannot-Link Constraints (CL)

$$\text{CL}(d_i, d_j) \implies c(d_i) \ne c(d_j)$$

Specifies that instances $d_i$ and $d_j$ cannot be in the same cluster. Non-transitive: $\text{CL}(a,b) \land \text{CL}(b,c) \not\implies \text{CL}(a,c)$.

COP-KMeans Algorithm (Wagstaff et al. 2001):

Modifies standard K-Means assignment step: An object $d_i$ is assigned to its nearest centroid $C_k$ only if assigning $d_i$ to $C_k$ does not violate any Must-Link or Cannot-Link constraints with previously assigned points. If all $k$ clusters violate a constraint, the algorithm fails and reports infeasibility.

Introduction to Outlier Analysis: Hawkins Definition & Scope

Outlier detection (anomaly detection) is the task of identifying data points that deviate substantially from the expected pattern or distribution of the remaining data.

Hawkins' Classic Definition (1980)
"An outlier is an observation which deviates so much from the other observations as to arouse suspicions that it was generated by a different mechanism."

High-Stakes Real-World Applications

  • • Credit Card Fraud: An abnormal transaction pattern (e.g., sudden overseas luxury jewelry purchase) amid routine domestic grocery spending.
  • • Cybersecurity Intrusion: A surge in outbound network socket traffic on unusual ports indicating data exfiltration or botnet compromise.
  • • Healthcare Diagnostics: A sudden spike in intracranial pressure or arrhythmia deviating from patient baseline vital signs.
  • • Industrial IoT Fault Detection: Vibration harmonics in aircraft turbines signaling micro-fractures prior to catastrophic failure.

The 3 Fundamental Outlier Classes (Han §12.1)

Outliers fall into three distinct conceptual categories based on their context and relationships:

1. Global Outliers (Point Anomalies)

An individual object that deviates significantly with respect to all other points in the entire universe of data.

Example: A transaction of \$10,000,000 in a retail grocery database where 99.9% of transactions are under \$200.

2. Contextual Outliers (Conditional Anomalies)

An object that deviates significantly with respect to a specific context, though its raw value is normal globally.

Example: A temperature reading of 32°C in Hyderabad during May is normal, but 32°C in Hyderabad in late December is a contextual outlier!

Requires 2 attribute classes: (1) Contextual attributes (e.g. date, location), and (2) Behavioral attributes (e.g. temperature, salary).
3. Collective Outliers

A group of data objects that collectively deviate from the entire dataset, even though individual objects in isolation appear benign.

Example: In a heart ECG, an individual cardiac voltage reading might be in the normal physiological range, but a flat horizontal sequence for 3 seconds constitutes a collective cardiac arrest anomaly.

Statistical Outlier Detection: Parametric & Non-Parametric

Statistical methods assume normal data points are generated by a stochastic model $\mathcal{M}(\theta)$, and objects with low probability density under $\mathcal{M}$ are declared outliers.

1. Univariate Normal Distribution & 3-Sigma Rule

$$Z = \frac{x - \mu}{\sigma} \implies \text{Outlier if } |Z| > 3$$

Under Gaussian assumption, $P(|X - \mu| > 3\sigma) \approx 0.0027$ (only 0.27% of observations).

2. Grubbs' Test (Extreme Studentized Deviate)

Formally tests the null hypothesis $H_0$: There are no outliers in the univariate sample.

$$G = \frac{\max_{i=1\dots n} |x_i - \bar{x}|}{s}$$

Reject $H_0$ at significance level $\alpha$ if $G > \frac{n-1}{\sqrt{n}} \sqrt{\frac{t^2_{\alpha/(2n), n-2}}{n - 2 + t^2_{\alpha/(2n), n-2}}}$.

3. Non-Parametric Boxplot (Tukey's IQR Method)

$$IQR = Q_3 - Q_1, \quad \text{Fence} = [Q_1 - 1.5 \cdot IQR, \; Q_3 + 1.5 \cdot IQR]$$

Does not assume Gaussianity. Extremely robust against skewed distributions.

Distance-Based Outlier Detection ($k$-NN Distance)

Distance-based methods avoid making parametric distributional assumptions by measuring the geometric isolation of objects.

Knorr & Ng Definition (1998):

An object $p$ in dataset $T$ is a $DB(r, \pi)$-outlier if at least fraction $\pi$ of the objects in $T$ lie at distance greater than radius $r$ from $p$.

$$\frac{|\{q \in T \mid \text{dist}(p, q) > r\}|}{|T|} \ge \pi$$

Distance-to-$k^{\text{th}}$-Nearest-Neighbor Metric

Define the outlier score of object $p$ as its distance to its $k^{\text{th}}$ nearest neighbor: $D^k(p)$. Rank all objects in descending order of $D^k(p)$; the top $m$ objects are declared outliers.

The Fatal Flaw of Distance-Based Detection: Distance-based methods implicitly assume a uniform density across the dataset. If the dataset contains clusters of different densities (e.g. a dense cluster $C_1$ and a sparse cluster $C_2$), points at the edge of sparse cluster $C_2$ will have larger $D^k$ than genuine outliers floating near dense cluster $C_1$!

Density-Based Outlier Detection: Local Outlier Factor (LOF)

To overcome the variable density trap, Breunig, Kriegel, Ng & Sander (SIGMOD 2000) introduced the Local Outlier Factor (LOF), which compares the density of an object to the densities of its local neighbors.

1. $k$-distance of $p$ ($d_k(p)$) & $k$-distance neighborhood ($N_k(p)$)

The distance $d(p, o)$ between $p$ and its $k^{\text{th}}$ nearest neighbor $o$. $N_k(p)$ contains all points within distance $d_k(p)$.

2. Reachability Distance of $p$ with respect to $o$

$$\text{reach-dist}_k(p, o) = \max\{d_k(o), d(p, o)\}$$

If $p$ is very close to $o$, the reachability distance is smoothed to $d_k(o)$. This prevents statistical instability for dense clusters.

3. Local Reachability Density ($\text{lrd}_k(p)$)

$$\text{lrd}_k(p) = \frac{|N_k(p)|}{\sum_{o \in N_k(p)} \text{reach-dist}_k(p, o)}$$

The inverse of the average reachability distance from neighbors to $p$.

4. Local Outlier Factor ($\text{LOF}_k(p)$)

$$\text{LOF}_k(p) = \frac{\sum_{o \in N_k(p)} \frac{\text{lrd}_k(o)}{\text{lrd}_k(p)}}{|N_k(p)|}$$

The average ratio of the local reachability density of $p$'s neighbors to that of $p$ itself.

Interpreting the LOF Score: • $\text{LOF} \approx 1.0$: Point has density similar to neighbors $\implies$ Inlier.
• $\text{LOF} < 1.0$: Point is in a high-density core surrounded by looser points $\implies$ Deep Inlier.
• $\text{LOF} \gg 1.0$: Point's density is dramatically lower than its neighbors $\implies$ Local Outlier!

LOF Step-by-Step Worked Numerical Calculation

⭐ High Probability Endsem Numerical Question

Consider 4 points on a 1D line: $A=0, B=1, C=2, P=6$. Let $k=2$. Let us compute $\text{LOF}_{k=2}(P)$.

Step 1: Compute 2-distances ($d_2$) and 2-distance neighborhoods ($N_2$)

For $A(0)$: Distances to $B(1), C(2) \implies d_2(A) = 2, \; N_2(A) = \{B, C\}$

For $B(1)$: Distances to $A(1), C(1) \implies d_2(B) = 1, \; N_2(B) = \{A, C\}$

For $C(2)$: Distances to $B(1), A(2) \implies d_2(C) = 2, \; N_2(C) = \{B, A\}$

For $P(6)$: Nearest 2 neighbors are $C(4)$ and $B(5) \implies d_2(P) = 5, \; N_2(P) = \{C, B\}$

Step 2: Compute Reachability Distances

For $B$: $\text{reach-dist}_2(A, B) = \max\{d_2(B), d(A,B)\} = \max\{1, 1\} = 1$; $\text{reach-dist}_2(C, B) = \max\{1, 1\} = 1$

$\implies \text{lrd}_2(B) = \frac{2}{1 + 1} = \mathbf{1.0}$

For $C$: $\text{reach-dist}_2(B, C) = \max\{d_2(C), d(B,C)\} = \max\{2, 1\} = 2$; $\text{reach-dist}_2(A, C) = \max\{2, 2\} = 2$

$\implies \text{lrd}_2(C) = \frac{2}{2 + 2} = \mathbf{0.5}$

For $P$: $\text{reach-dist}_2(P, C) = \max\{d_2(C), d(P,C)\} = \max\{2, 4\} = 4$; $\text{reach-dist}_2(P, B) = \max\{d_2(B), d(P,B)\} = \max\{1, 5\} = 5$

$\implies \text{lrd}_2(P) = \frac{2}{4 + 5} = \frac{2}{9} \approx \mathbf{0.2222}$

Step 3: Compute $\text{LOF}_2(P)$

$$\text{LOF}_2(P) = \frac{\frac{\text{lrd}_2(C)}{\text{lrd}_2(P)} + \frac{\text{lrd}_2(B)}{\text{lrd}_2(P)}}{2} = \frac{\frac{0.5}{2/9} + \frac{1.0}{2/9}}{2} = \frac{2.25 + 4.5}{2} = \mathbf{3.375}$$

Since $\text{LOF}_2(P) = 3.375 \gg 1.0$, $P$ is unambiguously flagged as a substantial local outlier!

Clustering-Based & Classification-Based Outlier Detection

Clustering and classification algorithms can be repurposed directly as high-performance anomaly detectors:

1. Clustering-Based Approaches
  • • Unassigned Points: In DBSCAN, all points that are neither core points nor border points are assigned to noise cluster $-1$.
  • • Distance to Centroid: In K-Means, objects whose distance to their assigned cluster centroid $\|x_i - \mu_{c(i)}\|$ exceeds a 99th percentile threshold are flagged.
  • • Small Cluster Outliers: Clusters containing fewer than $\theta_{\text{size}}$ objects (e.g. $< 1\%$ of data) are declared collective outlier clusters.
2. One-Class Support Vector Machine (Schölkopf et al. 2001)

Maps training data into a high-dimensional feature space via an RBF kernel and finds a maximum margin hyperplane that separates the data from the coordinate origin. Outliers lie on the wrong side of the boundary.

3. Isolation Forest (Liu et al. 2008)

Builds an ensemble of random decision trees (iTrees). Outliers are few and different, so they are isolated near the root of the tree with very short path lengths $h(x)$!

Trends: Spatio-Temporal & Trajectory Data Mining

With widespread GPS tracking, smartphones, and connected vehicles, spatio-temporal data mining has become an indispensable branch of data analytics.

Tobler's First Law of Geography (Spatial Autocorrelation):
"Everything is related to everything else, but near things are more related than distant things."

Violates the standard statistical assumption that data observations are independent and identically distributed (i.i.d.)!

Moving Object Trajectory Patterns

1. Moving Cluster: A density-connected group of objects whose membership changes slightly over time, but the overall cluster migrates smoothly across consecutive timestamps.
2. Convoy: A group of at least $m$ objects that remain density-connected with the exact same membership for at least $k$ consecutive time steps.
3. Swarm: Relaxes the consecutive constraint: at least $m$ objects travel together for at least $k$ (possibly non-consecutive) time intervals.

Trends: Graph & Social Network Mining

Graph structures model complex relationships across social networks, biological protein interactions, citation networks, and the World Wide Web.

1. Frequent Subgraph Mining (gSpan, FSG)

Finds subgraphs appearing in at least $\text{min\_sup}$ graph transactions. Challenges: Subgraph isomorphism testing is NP-Complete! Solved using canonical DFS code lexicographical ordering.

2. PageRank (Brin & Page 1998)

Models a random web surfer with damping factor $d \approx 0.85$:

$$PR(u) = \frac{1-d}{N} + d \sum_{v \in B(u)} \frac{PR(v)}{L(v)}$$

Converges via power iteration to the stationary distribution of the Markov transition matrix.

3. Community Detection & Modularity

Partitions graph into dense subgraphs with high internal connectivity and sparse external inter-community edges using Newman-Girvan Modularity $Q$.

The Curse of Dimensionality & Empty Space Phenomenon

As the number of dimensions $d$ grows into hundreds or thousands, geometric properties behave in deeply counter-intuitive ways:

1. Distance Concentration

Beyer et al. (1999) proved that under broad data distributions, the ratio between maximum and minimum Euclidean distance between points approaches 1:

$$\lim_{d \to \infty} \frac{d_{\max} - d_{\min}}{d_{\min}} = 0$$

Every point becomes equidistant from every other point! Nearest-neighbor queries lose all discriminative power.

2. The Empty Space Phenomenon

Consider a unit hypercube $[-1, 1]^d$ and inscribed hypersphere of radius $1$. The volume ratio of the hypersphere approaches 0 exponentially:

$$\frac{\text{Vol}(S^d)}{\text{Vol}(C^d)} = \frac{\pi^{d/2}}{2^d \Gamma(d/2 + 1)} \xrightarrow{d \to \infty} 0$$

Almost 100% of the volume of high-dimensional space is concentrated in the corners! Datasets become extremely sparse.

Concept 1

What is the query time complexity of STING and why?

Click to reveal answer ↻
Answer

STING query time complexity is $O(K)$, where $K$ is the number of grid cells at the bottom layer. Because cells store precomputed statistical summary parameters (count, mean, stdev, min, max, distribution), query processing inspects cells hierarchically without scanning the $N$ raw database tuples. Hence, $O(K) \ll O(N)$.

Concept 2

Why does distance-based outlier detection fail in multi-density datasets?

Click to reveal answer ↻
Answer

Distance-based methods ($k$-NN distance $D^k$) measure absolute Euclidean distance. In a dataset with a very dense cluster and a very sparse cluster, legitimate inliers in the sparse cluster naturally have larger $D^k$ than genuine outliers floating outside the dense cluster. LOF solves this by taking relative ratios of local reachability densities.

Concept 3

What is the difference between a Trajectory Convoy and a Swarm?

Click to reveal answer ↻
Answer

A Convoy requires at least $m$ objects to remain density-connected for at least $k$ consecutive timestamps. A Swarm relaxes the consecutive constraint: the objects must travel together for at least $k$ timestamps, but the timestamps can be non-consecutive.
