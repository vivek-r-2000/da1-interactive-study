Biological vs Artificial Neuron (Han 4th Ed §10.1)

Artificial Neural Networks (ANNs) draw biological inspiration from the human central nervous system, which contains roughly $10^{11}$ interconnected neurons operating with massive parallelism.

Biological Brain Anatomy

  • Dendrites: Branching nerve fibers that receive electrical pulses from adjacent neurons.
  • Soma (Cell Body): Sums electrochemical input signals across all dendrites.
  • Axon: Transmission line sending action potentials when the soma threshold is reached.
  • Synapse: Junction gap between axon and dendrites; synaptic plasticity controls connection strength.

Artificial Neuron Equivalent

  • Input Vector $\vec{x}$: Features $(x_1, x_2, \dots, x_d)$ entering the node.
  • Weights $\vec{w}$: Synaptic weights $(w_1, w_2, \dots, w_d)$ scaling inputs.
  • Summation $\Sigma$: Linear aggregation $z = \sum_{i=1}^d w_i x_i + b$.
  • Activation Function $\sigma(z)$: Non-linear firing gate producing output signal $a$.
McCulloch-Pitts Neuron (1943): The earliest mathematical model of a binary threshold neuron: inputs $x_i \in \{0, 1\}$ are weighted and compared against threshold $\theta$. If $\sum w_i x_i \ge \theta$, output is $1$, else $0$.

The Perceptron Model (Rosenblatt 1958)

Frank Rosenblatt extended the threshold neuron by introducing an adaptive weight learning algorithm that converges if the training data is linearly separable.

Perceptron Net Input & Activation
$$z = \mathbf{w}^T \mathbf{x} + b = \sum_{i=1}^d w_i x_i + b$$
$$y = f(z) = \begin{cases} +1 & \text{if } z \ge 0 \\ -1 \text{ (or } 0) & \text{if } z < 0 \end{cases}$$

The Perceptron Learning Rule

Given learning rate $\eta \in (0, 1]$ and target label $t \in \{-1, +1\}$:

  1. Initialize weights $\vec{w}$ and bias $b$ to zeros or small random numbers.
  2. For each sample $(\vec{x}, t)$, compute output $\hat{y} = \text{sign}(\mathbf{w}^T \mathbf{x} + b)$.
  3. If $\hat{y} \ne t$, update parameters: $$\mathbf{w} \leftarrow \mathbf{w} + \eta (t - \hat{y}) \mathbf{x}$$ $$b \leftarrow b + \eta (t - \hat{y})$$
  4. Repeat until all samples are correctly classified (zero training errors).
Novikoff's Perceptron Convergence Theorem (1962): If a training set is linearly separable with margin $\gamma > 0$ and maximum input radius $R = \max \|\mathbf{x}\|$, the Perceptron algorithm will make at most $(R / \gamma)^2$ weight updates before converging to a separating hyperplane.

Linear Separability & The XOR Barrier (Minsky & Papert 1969)

A single perceptron defines a linear decision boundary: a straight line in 2D ($w_1 x_1 + w_2 x_2 + b = 0$), a plane in 3D, and a hyperplane in higher dimensions.

AND Gate (Separable)

Weights: $w_1=1, w_2=1, b=-1.5$

$(0,0) \to -1.5 \to 0$

$(1,0) \to -0.5 \to 0$

$(0,1) \to -0.5 \to 0$

$(1,1) \to +0.5 \to 1$ ✓

OR Gate (Separable)

Weights: $w_1=1, w_2=1, b=-0.5$

$(0,0) \to -0.5 \to 0$

$(1,0) \to +0.5 \to 1$

$(0,1) \to +0.5 \to 1$

$(1,1) \to +1.5 \to 1$ ✓

XOR Gate (Non-Separable!)

Outputs: $(0,0)\to 0, (1,1)\to 0$, but $(1,0)\to 1, (0,1)\to 1$

No single straight line can separate $(0,1), (1,0)$ from $(0,0), (1,1)$! Single perceptron loops indefinitely.

The First AI Winter: Minsky & Papert's 1969 book Perceptrons proved mathematically that single-layer perceptrons cannot compute XOR. This halted neural network funding for over a decade until the discovery of the Multi-Layer Perceptron and Backpropagation.

Multi-Layer Perceptrons (MLP) & Hidden Representations

An MLP inserts one or more hidden layers between the input and output layers. The hidden units transform the original input space into a new non-linear feature space where the classes become linearly separable!

Solving XOR with 2 Hidden Nodes + 1 Output Node

Hidden node $h_1$ computes $x_1 \text{ OR } x_2$. Hidden node $h_2$ computes $\text{NAND}(x_1, x_2) = \text{NOT}(x_1 \text{ AND } x_2)$. Output node $y$ computes $h_1 \text{ AND } h_2$!

$$x_1 \oplus x_2 = (x_1 \lor x_2) \land \neg(x_1 \land x_2)$$

Universal Approximation Theorem (Cybenko 1989, Hornik 1991)

A feed-forward neural network with a single hidden layer containing a finite number of non-linear neurons (e.g., sigmoid activations) can approximate any continuous function on compact subsets of $\mathbb{R}^n$ to arbitrary precision $\epsilon > 0$.

Key Caveat: The theorem proves existence of such a network; it does not guarantee that gradient descent will find the optimal weights in polynomial time!

Activation Functions: Sigmoid, Tanh, ReLU & Derivatives

Without non-linear activation functions, a 100-layer neural network collapses into a single linear matrix multiplication: $\mathbf{W}_3(\mathbf{W}_2(\mathbf{W}_1 \mathbf{x})) = (\mathbf{W}_3 \mathbf{W}_2 \mathbf{W}_1)\mathbf{x} = \mathbf{W}_{\text{comb}}\mathbf{x}$. Non-linearity is essential!

1. Logistic Sigmoid Function $\sigma(z)$ Range: (0, 1)

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z))$$

Maps net input to probability. Weakness: Max derivative is $0.25$ (at $z=0$); causes severe vanishing gradient in deep layers. Not zero-centered.

2. Hyperbolic Tangent $\tanh(z)$ Range: (-1, +1)

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}, \quad \tanh'(z) = 1 - \tanh^2(z)$$

Zero-centered (mean output near 0), speeding up training compared to sigmoid. Still saturates at large $|z|$.

3. Rectified Linear Unit (ReLU) Range: [0, $\infty$)

$$f(z) = \max(0, z), \quad f'(z) = \begin{cases} 1 & z > 0 \\ 0 & z < 0 \end{cases}$$

The modern deep learning standard. Derivative is 1 for positive inputs (no gradient vanishing!). Computationally cheap. Risk: "Dying ReLU" if neurons receive large negative updates.

Softmax & Output Layer Selection for Tasks

The choice of activation function at the final output layer depends strictly on the supervised learning task objective:

Task Type Output Layer Nodes Output Activation Standard Loss Function
Continuous Regression 1 (or $m$ continuous targets) Linear / Identity ($a = z$) Mean Squared Error (MSE)
Binary Classification 1 node ($P(y=1|\mathbf{x})$) Sigmoid $\sigma(z)$ Binary Cross-Entropy
Multi-Class Classification ($K$ classes) $K$ nodes Softmax $\hat{y}_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$ Categorical Cross-Entropy
Properties of Softmax: 1. Ensures all outputs lie strictly in $(0, 1)$.
2. Ensures $\sum_{k=1}^K \hat{y}_k = 1.0$ (a valid probability distribution over mutual classes).
3. Monotonic: Higher logits $z_k$ always yield higher probabilities $\hat{y}_k$.

Matrix Formulation of Forward Propagation

Modern deep learning frameworks (PyTorch, TensorFlow) compute entire layers and batches simultaneously through vectorized linear algebra operations:

For any layer $l \in \{1, 2, \dots, L\}$:

$$\mathbf{z}^{[l]} = \mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}$$
$$\mathbf{a}^{[l]} = g^{[l]}(\mathbf{z}^{[l]})$$

Where $\mathbf{a}^{[0]} = \mathbf{x}$ (the raw input vector), and $g^{[l]}(\cdot)$ is the layer's activation function.

Dimensionality Verification (Crucial for Exams)

  • Let layer $l-1$ have $n^{[l-1]}$ neurons, and layer $l$ have $n^{[l]}$ neurons.
  • Weight matrix $\mathbf{W}^{[l]}$ has shape: $(n^{[l]} \times n^{[l-1]})$.
  • Bias vector $\mathbf{b}^{[l]}$ has shape: $(n^{[l]} \times 1)$.
  • Activation vector $\mathbf{a}^{[l]}$ has shape: $(n^{[l]} \times 1)$.
  • For a mini-batch of $m$ training samples: $\mathbf{A}^{[l-1]}$ has shape $(n^{[l-1]} \times m)$, and $\mathbf{Z}^{[l]} = \mathbf{W}^{[l]} \mathbf{A}^{[l-1]} + \mathbf{b}^{[l]}$ uses broadcasting to shape $(n^{[l]} \times m)$.

Loss & Cost Functions (Han 4th Ed §10.1)

A Loss function $L(\hat{y}, y)$ measures error on a single training example. The Cost function $J(\mathbf{W}, \mathbf{b})$ averages the loss across the entire training dataset of $n$ samples.

1. Mean Squared Error (MSE / L2 Loss)

$$J(\mathbf{W}, \mathbf{b}) = \frac{1}{2n} \sum_{i=1}^n \|\hat{\mathbf{y}}^{(i)} - \mathbf{y}^{(i)}\|^2$$

Standard for regression. In classification with sigmoid activations, MSE produces a non-convex loss surface with numerous local minima and slow plateaus!

2. Cross-Entropy Loss (Log Loss)

$$J(\mathbf{W}, \mathbf{b}) = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_k^{(i)} \log \hat{y}_k^{(i)}$$

Derived from Maximum Likelihood Estimation (MLE). When combined with Softmax, the loss surface is strictly convex and gradients are proportional to linear error $(\hat{y}_k - y_k)$, preventing training slowdown!

Why Cross-Entropy Beats MSE for Classification: If a sigmoid neuron is severely wrong ($\hat{y} \approx 0$ when $y = 1$), $\sigma'(z) \approx 0$. In MSE, gradient $\frac{\partial J}{\partial w} = (\hat{y} - y)\sigma'(z)x \approx 0$, so the neuron learns virtually nothing! In Cross-Entropy, the $\sigma'(z)$ term cancels out exactly, leaving $\frac{\partial J}{\partial z} = \hat{y} - y$, driving immediate fast updates.

Gradient Descent Variants: Batch, Stochastic & Mini-Batch

Neural networks optimize weights by stepping in the direction opposite to the cost gradient: $\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla_\mathbf{w} J(\mathbf{w})$.

1. Batch Gradient Descent (BGD)

Computes gradient over all $N$ training examples before updating weights once.

Pros: Stable convergence to minimum. Cons: Extremely slow for big datasets; cannot fit in GPU RAM.

2. Stochastic Gradient Descent (SGD)

Updates weights after evaluating every single individual example $(x^{(i)}, y^{(i)})$.

Pros: Fast updates; noisy path helps escape shallow local minima. Cons: Highly oscillatory, never settles smoothly at minimum.

3. Mini-Batch Gradient Descent (Standard Practice)

Computes gradient on small random batches of size $B \in \{32, 64, 128, 256\}$.

Pros: Leverages vectorized matrix arithmetic on GPU hardware; robust balance of speed and stability.

The Backpropagation Algorithm: Detailed Derivation

Backpropagation (Rumelhart, Hinton & Williams 1986) applies the multivariate Chain Rule of Calculus to calculate the exact partial derivative $\frac{\partial E}{\partial w_{ij}}$ for every weight in the network.

Step 1: Gradient for Output Layer Weights ($w_{jk}$ connecting hidden node $j$ to output $k$)

$$\frac{\partial E}{\partial w_{jk}} = \frac{\partial E}{\partial y_k} \cdot \frac{\partial y_k}{\partial z_k} \cdot \frac{\partial z_k}{\partial w_{jk}}$$

Since $z_k = \sum_j w_{jk} a_j + b_k$, we have $\frac{\partial z_k}{\partial w_{jk}} = a_j$. Defining output error $\delta_k \equiv \frac{\partial E}{\partial z_k} = \frac{\partial E}{\partial y_k} \sigma'(z_k)$:

$$\frac{\partial E}{\partial w_{jk}} = \delta_k \cdot a_j$$

Step 2: Gradient for Hidden Layer Weights ($w_{ij}$ connecting input $i$ to hidden node $j$)

$$\frac{\partial E}{\partial w_{ij}} = \frac{\partial E}{\partial z_j} \cdot \frac{\partial z_j}{\partial w_{ij}} = \delta_j \cdot x_i$$

Where hidden node error $\delta_j$ backpropagates errors from all connected output nodes $k$:

$$\delta_j = \left( \sum_{k \in \text{outputs}} \delta_k w_{jk} \right) \cdot \sigma'(z_j)$$

Step 3: Weight and Bias Parameter Updates

$$w \leftarrow w - \eta \frac{\partial E}{\partial w}, \quad b \leftarrow b - \eta \delta$$

Step-by-Step Worked Numerical Example (Textbook §10.1 Walkthrough)

⭐ High Probability Endsem Numerical Question

Consider a 2-input, 2-hidden, 2-output feedforward network with sigmoid activations ($\eta = 0.5$):

  • Inputs: $x_1 = 0.05, x_2 = 0.10$. Biases: $b_1 = 0.35, b_2 = 0.60$.
  • Input-to-hidden weights: $w_1 = 0.15, w_2 = 0.20, w_3 = 0.25, w_4 = 0.30$.
  • Hidden-to-output weights: $w_5 = 0.40, w_6 = 0.45, w_7 = 0.50, w_8 = 0.55$.
  • Target outputs: $t_1 = 0.01, t_2 = 0.99$.
Phase 1: Forward Pass

$z_{h1} = w_1 x_1 + w_2 x_2 + b_1 = 0.15(0.05) + 0.20(0.10) + 0.35 = 0.3775$

$a_{h1} = \sigma(0.3775) = \frac{1}{1 + e^{-0.3775}} \approx \mathbf{0.59326999}$

$z_{h2} = w_3 x_1 + w_4 x_2 + b_1 = 0.25(0.05) + 0.30(0.10) + 0.35 = 0.3925 \implies a_{h2} \approx \mathbf{0.59688438}$

$z_{o1} = w_5 a_{h1} + w_6 a_{h2} + b_2 = 0.4(0.59327) + 0.45(0.59688) + 0.6 = 1.1059 \implies a_{o1} \approx \mathbf{0.75136507}$

$z_{o2} = w_7 a_{h1} + w_8 a_{h2} + b_2 = 0.5(0.59327) + 0.55(0.59688) + 0.6 = 1.2249 \implies a_{o2} \approx \mathbf{0.77292847}$

Total Error: $E_{\text{total}} = \frac{1}{2}(t_1 - a_{o1})^2 + \frac{1}{2}(t_2 - a_{o2})^2 = 0.27481 + 0.02356 = \mathbf{0.29837111}$

Phase 2: Backward Pass for Output Weight $w_5$

$\delta_{o1} = \frac{\partial E}{\partial z_{o1}} = (a_{o1} - t_1) \cdot a_{o1}(1 - a_{o1}) = (0.75137 - 0.01) \cdot 0.75137(1 - 0.75137) = \mathbf{0.13849856}$

$\frac{\partial E}{\partial w_5} = \delta_{o1} \cdot a_{h1} = 0.13849856 \cdot 0.59326999 = \mathbf{0.08216704}$

Updated $w_5^+ = w_5 - \eta \frac{\partial E}{\partial w_5} = 0.40 - 0.5(0.08216704) = \mathbf{0.35891648}$

Phase 3: Backward Pass for Hidden Weight $w_1$

$\delta_{o2} = (a_{o2} - t_2) a_{o2}(1 - a_{o2}) = (0.77293 - 0.99) \cdot 0.77293(0.22707) = \mathbf{-0.03809824}$

$\delta_{h1} = (\delta_{o1} w_5 + \delta_{o2} w_7) \cdot a_{h1}(1 - a_{h1}) = (0.1385(0.4) + (-0.0381)(0.5)) \cdot 0.59327(0.40673) = \mathbf{0.0087714}$

$\frac{\partial E}{\partial w_1} = \delta_{h1} \cdot x_1 = 0.0087714 \cdot 0.05 = \mathbf{0.00043857}$

Updated $w_1^+ = w_1 - \eta \frac{\partial E}{\partial w_1} = 0.15 - 0.5(0.00043857) = \mathbf{0.14978071}$

Learning Rate $\eta$, Momentum & Convergence Dynamics

The learning rate $\eta$ is the single most critical hyperparameter in neural network training:

Too Large ($\eta > 1.0$)

Overshoots valleys, oscillates wildly, and eventually causes the cost function to diverge ($J \to \infty$ or NaN).

Too Small ($\eta < 0.0001$)

Extremely slow progress. High risk of getting permanently trapped in shallow local minima or saddle points.

Optimal or Decaying

Starts with moderate $\eta$ to explore, then decays $\eta_t = \frac{\eta_0}{1 + kt}$ to settle into sharp global minima.

Momentum Acceleration ($\alpha$ or $\beta \approx 0.9$):

Incorporates previous weight change velocity like a heavy ball rolling down a hilly terrain:

$$\Delta \mathbf{w}_t = \alpha \Delta \mathbf{w}_{t-1} - \eta \nabla J(\mathbf{w}_t)$$

Dampens oscillations across steep ravines and accelerates motion along flat plateaus.

Overfitting & Regularization Strategies

Deep neural networks have millions of parameters and can easily memorize noisy training data, leading to severe generalization failure (high variance).

1. L2 Weight Decay (Ridge Regularization)

$$J_{\text{reg}}(\mathbf{w}) = J(\mathbf{w}) + \frac{\lambda}{2} \sum w_i^2 \implies \mathbf{w} \leftarrow (1 - \eta \lambda)\mathbf{w} - \eta \nabla J$$

Penalizes large weights, favoring smoother decision boundaries that do not react excessively to single outliers.

2. Dropout (Srivastava et al. 2014)

During each training forward pass, randomly deactivate a fraction $p$ (e.g., 50%) of hidden units.

Prevents co-adaptation of features. Effectively trains an ensemble of $2^N$ thinned subnetworks!

3. Early Stopping

Monitor validation error at every epoch. Save network weights when validation loss hits minimum; halt when validation loss starts rising for $E$ consecutive patience epochs.

Vanishing & Exploding Gradients in Deep Architectures

In deep networks with $L$ layers, backpropagation multiplies derivatives across all consecutive layers: $\frac{\partial E}{\partial z_1} = \frac{\partial E}{\partial z_L} \prod_{l=1}^{L-1} \mathbf{W}^{[l+1]} \sigma'(z_l)$.

The Vanishing Gradient Problem

When using Sigmoid ($\max \sigma'=0.25$) or Tanh ($\max \tanh'=1$), repeated multiplication of numbers $< 1$ causes gradients in early layers to decay exponentially ($0.25^{10} \approx 9.5 \times 10^{-7}$).

Result: Lower layers never learn; network acts like a shallow model.

Architectural Solutions
  • • ReLU Activation: Gradient is exactly $1.0$ for $z>0$, eliminating decay.
  • • He / Xavier Weight Initialization: Scales initial weights with $\sqrt{2 / n_{\text{in}}}$.
  • • Batch Normalization: Normalizes inputs to zero mean and unit variance per layer.
  • • Residual Connections (ResNets): Skip connections $\mathbf{a}^{[l+2]} = g(\mathbf{z}^{[l+2]} + \mathbf{a}^{[l]})$ let gradients flow unhindered.

Concept 1

Why did Minsky & Papert claim perceptrons cannot learn XOR?

Click to reveal answer ↻
Answer

A single perceptron forms only a single linear hyperplane. In XOR, points $(0,1)$ and $(1,0)$ (class 1) lie on the opposite diagonal of $(0,0)$ and $(1,1)$ (class 0). No single line can separate them. An MLP with at least one hidden layer is required to fold the feature space.

Concept 2

What is the exact Backpropagation error term $\delta_k$ at the output layer?

Click to reveal answer ↻
Answer

$\delta_k = \frac{\partial E}{\partial z_k} = \frac{\partial E}{\partial y_k} \sigma'(z_k)$. For Squared Error Loss $E = \frac{1}{2}(t_k - y_k)^2$, $\frac{\partial E}{\partial y_k} = (y_k - t_k)$. For Sigmoid activation, $\sigma'(z_k) = y_k(1 - y_k)$. Hence $\delta_k = (y_k - t_k) y_k (1 - y_k)$.

Concept 3

Why does ReLU solve vanishing gradients while Sigmoid fails?

Click to reveal answer ↻
Answer

Sigmoid's derivative $\sigma'(z)$ has a maximum value of $0.25$ at $z=0$, and rapidly approaches $0$ as $|z|$ grows. In deep networks, multiplying numbers $\le 0.25$ layer-by-layer causes gradients to decay exponentially to $0$. In contrast, $\text{ReLU}'(z) = 1.0$ for all $z > 0$, propagating gradients unchanged regardless of depth.
